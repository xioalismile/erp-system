# 03 库存管理 测试用例

## 范围与风险点

- 覆盖：即时库存、批次库存、库存流水、其他入库单、其他出库单、库存调拨单、库存盘点单、生产领料单。
- 风险一：审核后数量对、金额不对（移动平均成本）；反审后金额没按原成本回滚。
- 风险二：超量出库、负库存是否被拦，以及拦在提交还是审核。
- 风险三：批次物料与无批次物料的库存行混在一起，形成正负两行。
- 风险四：删除已生效单据时库存是否对冲（本项目口径：已生效删除先对冲库存）。

**通用断言**：每条单据审核后到「即时库存」看该物料该仓的**库存数量**与**库存移动平均成本**两个数；反审后再看一次，必须回到审核前。

## 一、即时库存 / 批次库存 / 库存流水

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| KC-001 | P0 | 测试原料B @原料仓 300、成本 20 | 即时库存搜索「TEST-RAW-002」 | 出现一行：数量 300、移动平均成本 20；单位、仓库正确 |
| KC-002 | P1 | 同上 | 按仓库筛选「原料仓」→ 搜索 | 只出现该仓行；清空筛选恢复 |

| KC-004 | P1 | 无成本字段权限的角色 | 打开即时库存 + 导出 Excel | 页面与导出都没有成本列（SZ-026 同口径） |
| KC-005 | P1 | 刚做过一次入库 | 打开库存流水，按物料筛选 | 出现该入库流水：单据号、方向（入）、数量、成本、时间正确 |

## 本模块最可能出问题的一条

**KC-024（调拨按原成本、不按单据单价）**：调拨最容易把"单据上填的价"当成成本写进调入仓，导致成本被污染。验证时故意在调拨单上填一个离谱单价（如 99），审核后到即时库存确认调入仓成本仍是原成本 10；反审后再看一次是否完整回滚。
