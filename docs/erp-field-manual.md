## 一、单据通用结构与字段控制

### 1.1 单据 = 表头 + 表体（金蝶/用友通用）

| 部分 | 内容 | 例子 |
|------|------|------|
| 表头（单据头） | 整单共有的信息 | 单据编号、日期、客户/供应商、部门、业务员、币种、整单折扣 |
| 表体（单据体/明细行） | 每行货物一条记录 | 存货编码、数量、单价、金额、税率、仓库、批号、预计交货日期 |
| 表尾 | 制单人、审核人、审核日期等 | 公共信息 |

### 1.2 字段四控制（用友T+单据设计，每个预置字段都有这4个开关）

| 控制 | 作用 | 备注 |
|------|------|------|
| 必录 | 界面上必须输入才能保存，带`*` | 系统预置的必录字段不允许改 |
| 可改 | 是否允许编辑 | 系统预置不可改的字段不允许改 |
| 记忆 | 是否记忆上一次录单的值 | 如"客户"记忆后，下次新增自动带出上次的客户 |
| 显示 | 是否在界面上显示 | 隐藏≠删除，随时可调出 |

### 1.3 金蝶单据三层类型概念

| 概念 | 作用 |
|------|------|
| 单据类型 | 控制单据的样式和页面布局 |
| 业务类型 | 满足不同业务场景的流程控制（如标准销售/以销定购/直运），关联行类型 |
| 行类型 | 定义业务方向、业务性质和关键控制点（明细行级） |

### 1.4 含税价与不含税价换算（金蝶/用友通用规则）

```
含税单价 = 单价(不含税) × (1 + 税率%)
当税率为0或未填税率时：含税单价 = 单价（不计算税额）
```
- 金蝶：录入单价或含税单价其中一个，另一个按税率自动算出；可设置"录入偏好"锁定只能录其中一种
- 用友：供应商/客户档案或存货档案维护税率后，单据自动带出；档案税率清空则不带

### 1.5 本币/原币双轨（用友T+外币业务）

外币单据每行金额字段成对出现：单价/金额/税额/含税单价/含税金额/折扣金额（原币）+ 本币单价/本币金额/...（按汇率换算）。改币种时原币价税额不变，本币按汇率自动重算；本位币汇率必须为1。

## 二、销售订单（金蝶云星空 + 用友T+）

### 2.1 金蝶云星空·销售订单

**功能定位**：销售组织与客户之间的销售协议，记录客户需求（货物规格、价格数量），下游可生成发货通知单/销售出库单/销售退货申请单/收款单。

**表头-基本信息**

| 字段 | 解释 |
|------|------|
| 单据编号 | 销售订单编号 |
| 单据类型 | 控制单据页面布局和业务类型 |
| 业务类型 | 确定数据流转业务流程及业务控制（标准销售/服务销售/以销定购等） |
| 订单日期 | 订单签订日期 |
| 单据状态 | 值：暂存、已提交、已生效 |

**表头-销售信息**

| 字段 | 解释 |
|------|------|
| 销售组织 | 处理报价/订单/发货/退货的功能性组织（按权限过滤） |
| 销售部门 / 销售组 / 销售员 | 销售组织下的行政组织 / 业务组 / 人员 |
| 客户 | 购买物料的客户（销售组织下有权限、可用的客户） |
| 联系人 / 联系人电话 / 联系地址 | 客户方联系信息 |
| 收货方 / 收货方联系人 / 收货地址 | 收货的客户及其信息（可与客户不同） |
| 收票方 | 本次交易的收票方 |
| 付款方 | 本次交易的付款方 |

> 要点：客户、收货方、收票方、付款方是4个独立字段，可以各不相同——这是集团客户多主体结算的场景。

**表头-财务信息**

| 字段 | 解释 |
|------|------|
| 本位币 | 核算组织的本位币 |
| 结算币别 / 汇率表 / 汇率日期 / 汇率 | 币别及换算体系 |
| 付款方式 | 值：赊销、现销 |
| 结算方式 | 可用的结算方式（电汇/承兑等） |
| 收款条件 | 根据它生成订单明细中的收款计划 |
| 含税 | 控制明细行录入的价格是否含税（整单开关） |
| 税额 / 金额 / 价税合计 | 整单汇总：税额汇总、不含税金额汇总、价税合计 |
| 累计预收款金额 | 预收款流程，下游单据反写 |
| 累计收款金额 | 非预收款流程，下游单据反写 |

> 要点："累计xx金额"类字段都是**下游单据审核后自动反写**的，不允许手工改——通过它可以一眼看到订单的执行进度。

**表头-其他（金蝶）**：版本管理（订单变更留版本）、收款计划、发货计划。

### 2.2 用友T+·销售订单

**表头**

| 栏目 | 说明 |
|------|------|
| 单据编号 / 单据日期 | 日期默认系统登录日期 |
| 客户 | 属性为"客户"或"客户/供应商"的往来单位 |
| 应收余额 | 针对当前**结算客户**的应收总额（开单时直接看到客户欠多少钱） |
| 结算客户 | 应收账款挂在谁名下（可与客户不同） |
| 部门 / 业务员 / 项目 | 经营核算维度 |
| 整单折扣 | **辅助表体折扣快速录入，业务发生以表体折扣为准** |
| 预计交货日期 | 签订订单时承诺给客户的交货日期（表头版，每行还可单独设） |
| 币种 / 汇率 | 修改币种，原币价税额不变，本位币按汇率自动换算 |
| 运输方式 / 送货地址 / 联系人 / 联系电话 | 收货信息 |
| 客户手机号 | 录入客户后默认取档案"默认地址"行的手机号，可改 |
| 合同号 | 关联合同 |
| 收款方式 | 对应结算客户的收款方式 |
| 订金金额 | 签订订单时收取的金额 |
| 来源单据 / 来源单号 | 流转生成当前单据的上游（报价单） |
| 按仓库拆单出库 | 同销货单表头描述 |

**表体-明细页签**

| 栏目 | 说明 |
|------|------|
| 条形码 | 扫码录入存货 |
| 客户存货编码 / 客户存货名称 | 按客户存货设置带入（客户用自己的编码称呼我们的货） |
| 存货编码 / 存货名称 / 规格型号 / 存货图片 | 属性为"销售、劳务费用"的存货 |
| 销售单位 | 实际业务发生时的计量单位 |
| 数量 | 销售单位的数量 |
| 计量单位组合 | 多计量时按大/中/小单位分别合计，可打印 |
| 计量单位2 / 数量2 / 换算率 | 辅计量体系 |
| 报价→折扣%→单价→税率%→含税单价 | 价格链：报价打折得单价 |
| 金额 / 税额 / 含税金额 / 折扣金额 | 行金额计算结果 |
| 本币系列（本币单价/本币金额/...） | 外币换算结果 |
| 预计交货日期 | **每行存货的交货日期**（分批发货时各行不同） |
| 赠品 | 赠品管理标记 |
| 行中止 | 选中则当前行不再后续执行（单据生效后才可操作） |
| 中止人 / 中止时间 | 执行中止的操作员和时间 |
| 累计执行数量 | 后续发货/出库的总数量（系统回写，看执行进度） |
| 来源单据 / 来源单号 | 行级来源（从报价单哪一行带过来） |

> 要点：①表体"预计交货日期"支持一行一个交期；②"行中止"可以只停掉订单的某一行，不用整单终止；③整单折扣只是录入辅助，真实折扣以表体为准。

## 三、销货单（用友T+，销售出库+立账合一）

**功能定位**：销售业务的确认单据。销货单立账流程时确定应收关系（是应收立账依据）；业务与仓库合同时，销货单也是出库确认单据。业务类型分：普通销售、销售退货。

**表头关键字段**

| 栏目 | 说明 |
|------|------|
| 业务类型 | 普通销售 / 销售退货 |
| 票据类型 | 凭据类型（收据/发票），带出客户最近一次记忆值 |
| 发票号 | 自动生成销售发票时按实际发票号填写 |
| 应收余额 | 针对当前结算客户的应收总额 |
| 会员 / 本次积分 | 会员零售场景 |
| 使用预收 | 使用以前的预收款和收款一起核销应收款（立账时有） |
| 交货日期 / 收款到期日 | 收款到期日影响收款预警、往来资金预测、账龄分析 |
| 仓库 | **辅助表体仓库快速录入，业务发生以表体仓库为准** |
| 收货仓库 | 总部与营销机构协同场景，指定销给加盟商哪个门店 |
| 出库类别 | 参照出入库类别档案 |
| 现结金额 | 收到货后现场收款金额（现结业务） |
| 抹零 | 处理抹零或凑整业务；可≠0但方向须与整单金额一致；\|抹零\|+\|使用预收\|≤\|整单含税金额\|；不影响表体单价 |

> 要点：销货单 = 出库 + 立账二合一（T+的"销货单立账"模式），比"销售出库单+销售发票分立"模式少一张单。

## 四、采购订单（金蝶云星空 + 用友T+）

### 4.1 金蝶云星空·采购订单

**功能定位**：采购组织与供应商之间的采购协议。下游可生成采购收货单/采购入库单/采购退货申请单；费用类物料生成应付单；走预付款流程生成付款单。

**表头-基本信息**：单据编号、单据类型、业务类型（标准采购/费用采购/VMI/集中采购）、订单日期、单据状态（暂存/已提交/已生效）——结构同销售订单。

**表头-采购信息**

| 字段 | 解释 |
|------|------|
| 采购组织 / 采购部门 / 采购组 / 采购员 | 采购体系维度 |
| 供应商 | 物料的供应商（按权限过滤） |
| 联系人 / 联系人电话 / 供应商联系地址 | 供应商联系信息 |
| 送货方 / 送货方联系人 / 送货方联系人电话 / 送货联系地址 | 送货的供应商（可与供应商不同） |
| 发票方 / 收款方 | 本次交易的开票方、收款方（多主体结算） |
| 供应商直运 | 显示是否属于直运销售业务生成的采购订单 |

**表头-财务信息**：本位币/结算币别/汇率体系、付款方式（赊购/现购）、结算方式、付款条件（生成付款计划）、含税开关、税额/金额/价税合计、累计预付款金额、累计付款金额（下游反写）。

**表体-物料明细**

| 字段 | 解释 |
|------|------|
| 产品类型（金蝶销售侧） | 标准产品 / 套件父项 / 套件子项 |
| 物料编码 / 规格型号 / 辅助属性 | 物料标识 |
| 计量单位 / 数量 | 主计量 |
| 辅助单位 / 辅助数量 | 辅计量（按换算率自动算） |
| 单价 / 含税单价 / 税率 / 折扣方式 / 折扣率 / 折扣额 | 价格体系 |
| 需求组织 / 需求部门 / 需求人 | 谁要的货（行级） |
| 收料组织 / 收料部门 / 收货门店 | 谁收货（行级） |
| 结算组织（行级） | 行级核算主体 |
| 是否赠品 / 备注 / 供应商物料编码 / 供应商物料名称 | 供应商对这货的叫法 |
| 交货日期 / 交货地点 / 交货地址 | 行级交期 |

### 4.2 用友T+·采购订单

**表头**（与销售订单对称）

| 栏目 | 说明 |
|------|------|
| 供应商 | 属性为"供应商"或"供应商/客户"的往来单位 |
| 预计到货日期 | 签订订单时供应商承诺的到货日期 |
| 到货地址 / 联系人 / 联系电话 | 收货方信息 |
| 付款方式 / 订金金额 | 签订单时支付的预付款 |
| 销售订单号 | 记录为哪个销售订单做的采购（以销定购跟踪） |
| 来源单据/来源单号 | 销售订单、预测单、请购单 |
| 整单折扣% | 辅助录入，业务以表体折扣为准 |

**表体关键字段**

| 栏目 | 说明 |
|------|------|
| 供应商存货编码 / 供应商存货名称 | 供应商存货设置带入 |
| 存货名称 | 属性为'外购、劳务费用'的存货（采购侧只可选外购属性） |
| 采购单位 / 数量 | 数量不能为0 |
| 可用量 / 现存量 | 当前行存货主计量的可用量/现存量（录单时直接看库存） |
| 报价 / 折扣% / 税率% / 单价 / 含税单价 | 单价可查最近10次历史交易价格 |
| 预计到货日期 | 每行存货的预计到货日期（行级交期） |
| 赠品 / 行中止 / 中止人 / 中止时间 | 行中止后当前行不再后续执行；订单在途量同步扣除 |
| 累计执行数量 / 累计执行数量2 | 后续进货或入库的总数量（系统回写） |
| 销售订单号（行级） | 未自动带入时可手工指定，用于销售订单跟踪 |

**录单规则（T+官方操作说明）**
- 交货日期必须 ≥ 单据日期（采购日期），否则保存失败
- 采购数量不能为0
- 审核按整单：选中一行点审核=整单审核
- 选单生单时：价格不从上游单据带入，按**价格策略**取数；只带回有"外购"属性的存货
- 整单折扣金额工具：把零头自动分摊到明细折扣金额，使整单凑整；按含税金额或金额比例分摊，最后一行用减法兜底

## 五、库存单据

### 5.1 调拨单（用友T+）

**功能定位**：存货从一个仓库转移到另一个仓库，一张单同时登记调出仓的减少和调入仓的增加，不用分别开出库单+入库单。

**表头**

| 栏目 | 说明 |
|------|------|
| 业务类型 | **同价调拨 / 异价调拨**。存在不核算仓时必须是异价调拨 |
| 调出仓库 / 调入仓库 | 两个仓库 |
| 差异金额 | 等于表体差异金额合计 |

**表体**

| 栏目 | 说明 |
|------|------|
| 调出金额 | 同价调拨：用户录入，重新计价不更新。异价调拨：系统按计价方式算，可改；未勾"手工确定成本"时重新计价会更新。不核算仓→核算仓方向默认0并清零 |
| 调入金额 | 同价调拨：等于调出金额（不显示）。异价调拨：用户录入（=调出成本+搬运费等调拨费用）。核算仓→不核算仓方向默认0并清零 |
| 差异金额 | = 调入金额 − 调出金额 |
| 手工确定成本 | 选中后按用户录入的单价/金额登账，重新计价时不变 |
| 失效日期 | 有效期管理存货不能为空 |
| 箱号 / 序列号 / 序列号个数 / 入库单号 | 装箱、序列号、批次追踪体系 |

> 要点：**同价调拨**=成本平移（调出=调入）；**异价调拨**=调入成本=调出成本+运输搬运费，用于准确核算调入仓实际成本。

### 5.2 盘点单（用友T+）

**功能定位**：证明存货盘盈盘亏、调整账实差异的书面凭证。批准前先记"待处理财产损溢"，批准后再转出。盘点类型分：存货盘点、倒冲盘点（现场仓按差异调整材料耗用）。

**表头**

| 栏目 | 说明 |
|------|------|
| 单据编号 | 在盘点单中唯一 |
| 盘点类型 | 存货盘点（默认）/ 倒冲盘点 |
| 账面日期 | **出入库账面截止日期**（盘点快照基准） |
| 盘点结束日期 | 盘点业务结束的实际日期 |
| 盘点仓库 | 不能为空；倒冲盘点时只能是现场仓/委外仓 |
| 出库类别 / 入库类别 | 默认"盘盈入库"/"盘亏出库"（注意：表头出库类别默认值对应盘盈、入库类别对应盘亏，按方向命名） |
| 部门 / 经手人 | 责任人 |

**表体**

| 栏目 | 说明 |
|------|------|
| 账面数量 | 库存现存量表中主计量数量，**系统自动提取** |
| 盘点数量 | 实际清点数量，**用户录入** |
| 盈亏数量 | = 盘点数量 − 账面数量；正=盘盈，负=盘亏 |
| 单价 | 按单价带入规则取（成本） |
| 账面金额 / 盘点金额 / 盈亏金额 | = 数量 × 单价 |
| 入库单号 | 个别计价存货盘亏时必须指定出库对应的入库单号（成本追踪） |

> 要点：盘点核心公式就一行：**盈亏数量 = 盘点数量 − 账面数量**，账面由系统按账面日期锁定提取，实盘人工录入。

## 六、生产管理单据（金蝶云星空 + 用友T+）

### 6.1 金蝶云星空·生产订单

**功能定位**：下达给生产车间的生产任务，车间据它组织生产、领料、产品入库。来源可以是销售订单选单（以销定产）或手工新增；返工订单选业务类型"汇报入库-返工生产"。

**表头/表体字段**

| 字段 | 解释 |
|------|------|
| 产品类型 | 主产品 / 联产品 / 副产品（不可编辑）。手工录物料=主产品；录入BOM后按BOM携带出联、副产品 |
| 物料编码 | 只可选择物料档案勾了"允许生产"的物料；联、副产品由主产品BOM携带，不可编辑 |
| 生产车间 | 完成工序或独立生产的生产单位（生产组织下有车间职能的部门）；订单下达前必录 |
| 单位 | 主产品默认携带物料的生产单位，可改 |
| 数量 | 计划生产的产品数量 |
| 业务状态 | 系统自动标识：计划→计划确认→下达→开工→完工→结案→结算 |
| 计划开工时间 | 默认当天；必须落在生产车间工厂日历的可生产日；≤计划完工时间 |
| 计划完工时间 | 由计划开工日期+生产数量自动计算；也须落在工厂日历可生产日 |
| BOM版本 | 默认携带用途为"自制+通用"的最新BOM版本；BOM版本影响计划时必录；未录BOM需手动维护用料清单 |
| 领料状态 | 未领料/部分领料/全部领料/超额领料（系统按领料套数自动判定，不可编辑） |
| 工艺路线 | 按产品生产数量和日期按规则默认获取，可修改；联、副产品不可设置 |
| 批号 | 批次管理物料可录入批号 |
| 入库上限 | =生产数量×物料档案入库超收比例，可改但必须≥数量（超收控制） |

**领料状态判定规则**（金蝶官方口径）：
- 领料套数=0 且无关联领料单 → 未领料
- 领料套数=0 但关联了领料单 → 部分领料
- 0 < 领料套数 < 生产数量 → 部分领料
- 领料套数 = 生产数量 → 全部领料
- 领料套数 > 生产数量 → 超额领料

**金蝶生产模块全家福**：生产用料清单（+变更单）、简单生产、生产领料/退料/补料、直接调拨、生产齐套分析、生产汇报（机器实作工时=加工消耗机器实际时间）、生产入库、生产订单拆分、生产挪料、月末在制转移。

### 6.2 用友T+·生产加工单

**功能定位**：下达给生产车间的生产任务。可作限额领料控制依据，也可作产品入库依据。来源：销售订单/预测单/请购单流转、手工录入、多阶投产（多层BOM一次生成成品+半成品任务）。

**表头**

| 栏目 | 说明 |
|------|------|
| 业务类型 | **正常**：产品、材料不允许循环引用；**返工**：材料明细可勾选"允许循环"，返工录产品不带默认BOM |
| 生产车间 / 负责人 / 项目 | 车间（部门档案）、负责人（员工档案）、项目维度 |
| 预开工日 / 预完工日 | 计划开始/完成生产的日期 |
| 开工日期 / 完工日期 | 实际开始/完成生产的日期 |
| 销售订单号 | 记录为哪个销售订单做的生产（销售订单跟踪） |
| 客户 | 为哪个客户生产；产品明细为多个客户时不显示 |
| 产品自动添加到材料 | 仅返工类型可勾选；勾选后新增产品自动进材料明细并自动勾"允许循环" |

**表体-产成品明细**

| 栏目 | 说明 |
|------|------|
| 产品编码/名称 | 属性为"**自制**"的存货（生产单只可选自制属性，与委外"委外"属性、采购"外购"属性区分） |
| 适用BOM / BOM展开方式 | 指定BOM及展开方式 |
| 工艺路线 | 默认取物料清单的工艺路线，物料清单无则取存货档案默认工艺路线 |
| 预入仓库 / 批号 | 完工产品入哪个仓、什么批号 |
| 生产单位 / 数量 | 实际业务计量单位 |
| 预开工日/预完工日/开工日期/完工日期 | **行级日期**（每个产品可单独排期） |
| 齐套数量(主) | 已领材料能齐套生产的最小套数（看材料够产几套） |
| 累计入库数量 / 累计入库数量2 | 后续产成品入库总数量（系统回写，主计量+辅计量） |
| 已采购需求分析 | 标记该行是否已跑采购需求分析 |
| 来源单据/来源单号 | 销售订单、请购单、预测单 |
| 现存量 / 可用量 | 录单时直接看该存货库存 |

**表体-材料明细**

| 栏目 | 说明 |
|------|------|
| 材料编码/名称 | 属性为"**生产耗用**"的存货 |
| 预出仓库 | 该材料从哪个仓出（支持按仓库分单打印给不同仓库备料） |
| 倒冲料 | 勾选后产成品入库时按定额自动生成材料出库单；**个别计价、先进先出存货不允许勾选** |
| 允许循环 | 勾选后保存时不判断该材料的父子件循环引用（返工场景：产品本身作为材料） |
| 领料工序 | 设置在哪道工序上领用该材料（配合工序汇报齐套控制） |

**生产业务场景（T+官方流程）**：接客户订单→PMC下加工单→打印给车间和仓库→看库存不满则下采购→到货后按加工单发料（材料出库单，业务类型"自制领料"；退料为"自制退料"）→完工入库（产成品入库单，"自制加工"；不合格退回为"自制退库"）→月底产品成本分配→生成凭证。

**多阶投产**：选投产单据（销售订单/预测单）→设投产方案→生成投产数据（数量−库存可用量）→投产类型自制生成生产加工单、委外生成委外加工单。

## 七、委外管理单据（金蝶云星空 + 用友T+）

### 7.1 金蝶云星空·委外订单与参数

**委外三前提**（金蝶）：①物料属性="委外加工"（成本来源选作业成本/标准成本）；②供应商档案业务信息页签勾"**委外商**"（不勾选不了委外订单）；③委外BOM（父项=委外加工件，子项=原材料，BOM里设**发料方式**=直接领用/调拨）。

**委外单据类型参数**（金蝶官方字段）

| 字段 | 说明 |
|------|------|
| 委外类型 | **标准委外**：按BOM生成委外用料清单；**返工委外**：用料清单=产品本身 |
| 用料清单 | 返工订单专用：仅为主产品（清单只显示主产品）/ 按BOM展开（按BOM产生子项物料） |
| 启用用料清单变更 | 启用后用料清单审核后不能直接重置草稿修改，要走变更单 |
| 调拨物料获取预设供应商仓库 | 委外订单指定供应商后，保存时自动把该供应商对应的委外仓库写入用料清单调拨物料的仓库字段 |
| 调拨考虑最小包装/最小发料批量 | 调拨时按物料档案最小包装量/最小发料批量的整数倍执行 |
| 委外订单结案考虑联副产品关闭 | 结案需联、副产品的采购订单整单关闭/业务关闭/业务终止 |
| 结案时子项材料损耗报失 | 结案时自动将在制数量中的损耗扣减，记入用料清单"结案损耗报失数量" |
| 委外订单审核时自动下达 | 勾选后审核即下达 |
| 下达时自动审核用料清单 | 勾选后下达即审用料清单 |
| 委外订单自动结案 | 满足结案条件自动结案 |
| 倒冲方式 | 交互式倒冲（通过倒冲平台）/ 后台倒冲（领料单生成时机后台自动倒冲） |
| 领料单生成时机 | 入库单**提交时** / 入库单**审核时**（要在入库时做材料领用控制的建议选提交时） |

**委外对账公式**（金蝶实操口径）：
- 应发数量 = 订单数量 × (1 + 损耗率)
- 应扣材料费 = 实际入库量 × BOM标准用量 × 材料单价
- 实扣材料费 = 实际发料量 × 材料单价
- 损耗差异 = 实发 − 应发，超发部分由客户承担或在加工费中体现

### 7.2 用友T+·委外加工单

**功能定位**：下达给委外加工商的加工任务，约定加工产品、数量、加工费价格、所需材料及数量；加工商据此领料、缴回产品。

| 客户 | 为哪个客户委外；多客户委外时不显示 |

**表体-产成品明细**（结构与生产加工单对称）

| 栏目 | 说明 |
|------|------|

### 7.3 用友T+·委外发料单

**功能定位**：委外加工商领用材料时企业填制的出库单。**不能手工录入，只能根据委外加工单发料**。

| 栏目 | 说明 |
|------|------|
| 业务类型 | **委外发料**（正常材料出库）/ **委外退料**（材料不合格或领用过剩退库） |
| 出库类别 | 出库业务分类 |
| 领用人 / 仓库 | 仓库为表头辅助录入，业务以表体仓库为准 |
| 加工单号（表头/表体） | 关联的委外加工单号；表体行可各对应不同加工单 |
| 产品编码（表体） | 标识当前行材料用于生产哪个产品（数量、单价、金额都是针对材料而言） |
| 材料编码/名称 | 属性"生产耗用"的存货 |
| 数量 | 本次实际发料数量 |
| 单价 | 按出库单价带入规则取（成本体系） |
| 出库调整 | 个别计价/先进先出存货入库成本变化引起的出库成本差异记录 |
| 累计退库数量 | 生成退料单时系统自动回写 |
| 入库单号 | 个别计价产品"委外发料"时必录（成本追踪到原入库单） |

### 7.4 倒冲领料与补料机制（T+13.0 官方规则）

**倒冲领料**（材料有最小包装无法按单领料/材料直发加工商仓库）：
- 仓库档案增加仓库类型：**现场仓、委外仓**
- 倒冲标识链：存货档案 → 物料清单 → 加工单材料明细（逐级快捷带入）
- 领料到现场仓：按加工单生成调拨单（不记录与加工单的关系，仅快速录入）
- **产成品入库单审核时**，加工单上有倒冲标识的材料自动生成材料出库单（建立与加工单的关系）
- 倒冲盘点：差异以当期倒冲领料数据为分摊依据，生成调差退料/材料出库单；无倒冲领料可分摊时生成其他出入库单

**补料**：
- 材料出库单增加业务类型"生产补料"；委外发料单增加"委外补料"，可单独设权限
- 补料单保存时**不判断是否超加工单材料数量**
- 选项可设置：补料时是否允许领加工单上不存在的材料
- "选生产加工单"=补已有材料的数量；"选生产加工单（新增材料）"=补新材料的数量（会更新加工单补料标识和累计补料数量；已补领过的材料不能再按新增材料方式补）

**工序汇报齐套控制**（T+Cloud）：
- 按领料齐套数量控制工序汇报：汇报数量上限=关联材料的齐套数量
- 支持全局上浮比例（如20%：领料10套最多汇报12个）
- 工序退回、材料退料不做控制

**供应商设置**：与客户设置对称（默认付款方式、进货/开票后X天内付款等账期参数）。

**联系方式页签**：多地址管理（到货地址、运输方式、联系人、手机、默认地址标记）——单据上"送货地址/客户手机号"默认取默认地址行的值。

**并户**：两个往来单位合并（档案、单据、应收应付、信用、权限全并过去），不同性质可并（并后变"客户/供应商"）。

## 九、自定义字段体系（金蝶/用友对照）

| 维度 | 用友T+ | 金蝶（星辰/精斗云） |
|------|--------|---------------------|
| 入口 | 系统管理→单据设计→自定义项设置 | 系统设置→个性化设置→单据新增字段 |
| 分类 | 专用自定义项（仅本单据）/ **公用自定义项**（可随单据流转到下游） | 表头字段/表体字段 |
| 类型 | 字符、数值、整数、日期、逻辑、枚举、引用 | 引用文本、数值、日期、引用辅助资料、引用基础资料 |
| 值来源 | 手工录入 / 基础档案 / 基础档案属性 / 系统信息 / 枚举档案 / 公式计算 / 自定义档案 | 基础资料及其属性带出 |
| 数量限制 | — | 标准版表头/表体各8个；专业版/旗舰版各20个 |
| 关键规则 | 公用自定义项设置"适用单据"后随流转带出；专用不流转 | 可带到下游单据、可作查询筛选条件；**不参与单据已有核算逻辑** |

**选型逻辑（T+官方建议）**：
- 每个存货都有的属性 → 存货自定义项；只有部分存货有 → 存货自由项（可控制取值范围）
- 基础档案阶段就能确定的属性 → 档案自定义项；制单时才能确定 → 单据自定义项
- 需要随上下游流转 → 公用自定义项；仅本单使用 → 专用自定义项

## 十、通用字段取值联动速查（两厂商共性规律）

| 字段 | 取值/联动规律 |
|------|--------------|
| 单据日期 | 默认系统登录日期，可改；做哪个月的业务用哪个月日期登录 |
| 税率% | 存货档案税率 →（空则）往来单位档案税率 →（空则）系统参数默认税率 |
| 单价（采购） | 价格策略/价目表 →（无则）历史交易价参照；上游单据价格**不**直接带入采购单 |
| 含税单价 | = 单价×(1+税率)，录一头自动算另一头 |
| 整单折扣 | 仅辅助录入，业务以表体折扣为准 |
| 累计执行/收款/付款数量金额 | 下游单据审核后自动反写，看执行进度 |
| 送货地址/手机号 | 默认取往来单位档案联系方式页签"默认地址"行 |
| 来源单据/来源单号 | 选单/流转生单时自动记录上游单据类型和编号 |
| 可执行数量（选单时） | = 订单数量 − 累计采购数量 − 累计生产数量，小于0显示0 |
| 行中止 | 停止某一行后续执行；在途量同步扣减；不影响其他行 |
| 停用档案 | 存货需各仓存量0；往来单位直接停用；停用后不参与业务 |
| 存货属性决定单据范围 | 销售单选"销售"属性、采购单选"外购"、生产单选"自制"、委外单选"委外"、材料明细选"生产耗用" |
| 齐套数量 | 已领材料按定额能生产的最小套数（生产/委外订单均有） |
| 入库上限（生产） | = 生产数量 × 物料档案入库超收比例 |
| 领料状态（生产） | 按"领料套数 vs 生产数量"自动判定：未领/部分/全部/超额 |
| 预计开完工日期 | 生产/委外单据表头+表体行级都可设；计划 vs 实际成对出现 |
| 倒冲料 | 入库审核时按定额自动生成材料出库单；个别计价/先进先出存货不可用 |
| 允许循环（返工） | 返工单里产品本身作材料时豁免父子件循环校验 |
