# 11 工作台、数据看板与系统通用 测试用例

> 覆盖：登录与租户、工作台、数据看板（财务/销售/仓储/经营/SPC）、消息中心、全局搜索、多语言、通用权限与异常页。

## 一、登录与租户

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| TY-101 | P0 | 无 | admin / 正确密码登录 | 进入租户选择；选中「A公司-完整模式」后进工作台 |
| TY-102 | P0 | 无 | 密码输错 | 提示账号或密码错误，停留在登录页；不显示技术堆栈 |
| TY-103 | P1 | 无 | 连错 5 次 | 按系统策略提示或锁定（记录实际）；不出现 500 |
| TY-104 | P0 | 已登录 | 顶部「切换公司」选另一个租户 | 菜单、数据切换为该租户；不残留上一个租户的列表数据 |
| TY-105 | P0 | 已登录 | 退出登录 | 回到登录页；浏览器后退不能回到业务页（token 已清） |
| TY-106 | P1 | 手动删除本地 token | 刷新任意业务页 | 跳回登录页并带 redirect，登录后回原页 |
| TY-107 | P1 | 已登录 | 直接访问 `/login` | 自动跳工作台（不再显示登录页） |

## 二、工作台

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| TY-108 | P0 | 有待办（待审核单据） | 打开工作台 | 待办卡片数量与「待审核」单据数一致；点卡片进入对应列表并带上筛选 |
| TY-109 | P1 | 无待办 | 打开工作台 | 显示 0 或空态，不报错 |
| TY-110 | P1 | 有库存预警 | 工作台预警卡片 | 数量与库存预警设置页一致；点进去能定位到物料 |
| TY-111 | P2 | 网络慢 | 打开工作台 | 各卡片独立加载，单个接口失败不导致整页白屏 |

## 三、数据看板

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| TY-112 | P0 | 当月有销售单据 | 打开销售看板 | 销售额、订单数、毛利等与销售单据合计一致（抽查一单核对） |
| TY-113 | P0 | 有库存 | 打开仓储看板 | 库存总量/金额与即时库存一致；低库存预警数与预警设置一致 |
| TY-114 | P1 | 有收付款/费用 | 打开财务看板 | 应收、应付、回款数与财务单据一致 |
| TY-115 | P1 | 有生产/采购数据 | 打开经营看板 | 采购额、产值等指标与来源单据合计一致 |
| TY-116 | P1 | 有质检记录 | 打开 SPC 质量看板 | 不良率/趋势图与质检记录一致 |
| TY-117 | P1 | 任一看板 | 切换日期区间 | 数值随之变化；跨月/跨年不出现空图或 NaN |
| TY-118 | P2 | 新租户无数据 | 打开各看板 | 空态提示，图表不裂开、不报错 |

## 四、消息中心 / 全局搜索

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| TY-119 | P0 | 有未读消息 | 点铃铛 | 未读数与实际一致；点「全部已读」后角标清零 |
| TY-120 | P1 | 消息列表 | 点某条消息 | 跳转到对应单据详情；无权限时提示而不是 403 白屏 |
| TY-121 | P0 | 有单据/物料/客户 | 顶部全局搜索输入单号 | 出现对应结果；点击进入正确页面 |
| TY-122 | P1 | 无权限的单据 | 用受限角色搜索 | 搜不到无权数据（服务端过滤，不是前端隐藏） |
| TY-123 | P2 | 搜索不存在的关键词 | 回车 | 空结果提示，不报错 |

## 六、通用权限与异常页

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| TY-127 | P0 | 无某菜单权限的角色 | 登录 | 该菜单不显示；直接输地址被拦到 403 或工作台 |
| TY-128 | P1 | 无权限页面 | 访问 `/403` | 页面有"返回工作台"按钮且能回 |
| TY-129 | P1 | 访问不存在的路由 | 输入 `/not-exist` | 不白屏；回工作台或 404 提示 |
| TY-130 | P2 | 任意列表页 | 双击菜单项 | 不产生重复标签页；页面不重复加载 |

## 本模块最可能出问题的一条

**TY-104（切换公司）**：多租户切换最容易出现"切了公司但列表还是上一家的数据"或"权限还是上一家的"。验证时在同一浏览器里 A 公司建一张单 → 切到 B 公司 → 确认列表里看不到那张单 → 再切回 A 确认还在；同时检查侧边栏菜单是否随租户权限同步。
