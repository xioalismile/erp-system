## 1. 模块概述

平台管理模块（`/admin` 路由前缀）是智能ERP SaaS 平台层的运维后台，**仅面向平台方的超级管理员**，**不向普通企业租户开放**。模块的三大子功能：

| 子模块 | 路由 | 主要能力 |
|--------|------|----------|
| 租户管理（列表） | `/admin/tenants` | 租户增删改查、启/停、冻结/解冻、续费、一键初始化、开通演示数据、切换管理员密码。 |
| 租户表单（弹窗） | `admin/tenants/new` 或 `edit/:id` | 在弹窗中录入企业信息、选择订阅版本、配置模块包、分配管理员账号、配置 Logo 与主题色。 |
| 部署管理 | `/admin/deploy` | 查看各租户的实际部署拓扑（数据库连接池、独立域名、对象存储配额、计算资源 CPU/内存用量）、重启租户服务、清理缓存、导出运维诊断包。 |

### 1.1 平台管理 vs 租户内系统设置的区别

| 维度 | 平台管理（本模块，SUPER_ADMIN） | 租户内系统设置（`SYS` 角色） |
|------|----------------------------------|-------------------------------|
| 作用范围 | 跨所有租户，平台级 | 只在单个租户内 |
| 典型操作 | 开通租户、配置版本、分配模块包、分配独立库 | 角色权限、用户管理、字典项、打印模板、参数配置 |
| 订阅版本 | 可改（购买升级） | 不可改（只能看当前版本信息） |
| 部署资源 | 可配置 CPU/内存/存储 | 只读看配额使用情况 |
| 初始化 | 可一键初始化基础档案（可选带演示数据） | 初始化仅限本租户内业务单（清空业务数据） |

## 2. 进入方式与权限说明

### 2.1 进入方式

- **平台管理员专用入口**：登录系统时，如果账号有 `SUPER_ADMIN` 角色，左侧导航菜单底部会出现「平台管理」菜单，展开有 2 个子菜单：「租户管理」「部署管理」。
- **快捷入口**：工作台底部（仅 SUPER_ADMIN 可见）「平台运维」卡片 → 点击跳租户列表。
- 普通租户账号即使知道路由 `/admin/tenants`，直接访问也会被全局路由守卫拦截并提示「403 无权限访问平台管理」。

### 2.2 权限说明（严格分层）

| 角色 | 说明 | 允许操作 |
|------|------|----------|
| `SUPER_ADMIN`（平台超级管理员） | 部署时默认创建 1~3 个账号，人数严格控制。 | 所有操作（租户增删改、改版本、改库、启/停、部署管理、重置租户管理员密码、初始化/清空数据、平台级参数）。 |
| `TENANT_ADMIN`（平台租户管理员） | 平台客服/运维岗位，允许日常运维但不碰关键配置。 | 租户查询/启停/续费/冻结；部署管理中查看资源与重启、清理缓存、导出诊断包；**禁止：新增租户、改订阅版本、删除租户、重置管理员密码**。 |
| 其他所有角色（含租户内 `ADMIN`） | 一律不可进入 `/admin` 路由。 | 无。 |

### 2.3 操作安全说明（强制，必须遵守）

> **代码安全与数据安全规范**（本模块操作涉及用户数据与生产环境，严格执行以下 4 条）：
> 1. **双因子登录**：SUPER_ADMIN 账号必须绑定短信 OTP 二次验证，每 7 天强制重新验证。异地登录立即锁定 24 小时并通知安全管理员。
> 2. **敏感操作审计**：本手册 5.4 节列出的所有「敏感操作」（删除租户、初始化清空、改库、重置管理员密码）必须执行操作前二次弹框（输入操作原因 + 当前账号登录密码确认），所有记录写入 `platform_audit_log` 表（10 年不可删除）。禁止在非生产环境之外用生产账号乱操作。
> 3. **禁止单步回滚=无回滚**：删除租户、一键清空数据类操作不可恢复，操作前必须在弹窗中勾选 3 个确认复选框：①我已备份数据 ②我知晓不可恢复 ③我对本次操作负责。
> 4. **版本管理**：模块权限包变更、订阅版本升级/降级，必须关联对应的销售订单/合同编号（TenantForm 中有「关联合同号」字段，升级时必填），严禁无合同私自给客户开高级模块。

## 3. 通用概念与状态体系

### 3.1 4 种订阅版本（Edition）

| Edition | 中文 | 说明 | 典型适用 |
|---------|------|------|----------|
| TRIAL | 试用版（免费） | 默认 30 天有效期，仅开 基础资料+销售+采购+库存 4 模块，演示数据可选，到期自动冻结。 | 新客户试用。 |
| STANDARD | 标准版（付费） | 基础 + 销售 + 采购 + 库存 + 财务（含应收应付）+ 报表中心；限制 5 个用户账号、10GB 存储。 | 小微客户。 |
| PROFESSIONAL | 专业版（付费） | 标准版基础 + 生产 + 委外 + 客户价格样品 CRM + 工作台 + 物流监控；用户数 50、存储 100GB；支持二开 API。 | 中型制造/工贸。 |
| ENTERPRISE | 企业版（付费） | 专业版基础 + 平台全部模块 + 获客管理 + 独立库 + 独立域名 + 指定服务器资源；不限用户/存储；含 SLA；支持私有化定制。 | 大型企业/集团。 |

> 详细对比表见附录 A。

### 3.2 模块权限包（Modules）

版本按「基础包 + 可选模块包」组合方式授予：
- 基础包：基础资料（必含，所有版本都有）。
- 包销售：销售管理、客户价格档案、客户对账单。
- 包采购：采购管理、供应商档案、供应商对账单。
- 包库存：库存管理、即时库存、盘点、批次。
- 包生产：生产工单、BOM、MRP、车间报工。
- 包委外：委外管理。
- 包财务应收应付：应收/应付单、核销、收款/付款。
- 包总账报表：财务总账、凭证、账簿、三大报表。
- 包CRM：价格样品、销售线索、客户公海私海。
- 包获客管理：获客任务/采集结果/企查查登录（VITE_HIDDEN_MODULES 中移除 acquisition）。
- 包物流监控：物流看板（同上，移除 logistics）。
- 包平台级：独立域名、独立库、独立资源配额。

### 3.3 租户状态体系

| 状态 | 英文 | 描述 | 用户侧可见行为 |
|------|------|------|----------------|
| 草稿 | DRAFT | 刚创建未保存详情，试用期/配置未完成。 | 不可登录，登录页提示「租户未激活」。 |
| 激活（正常） | ACTIVE | 已配置并启用，服务运行中。 | 正常登录和使用。 |
| 已冻结 | FROZEN | 运营冻结（欠费、违规、客户主动申请暂停）。 | 登录后提示「租户已冻结，请联系平台客服」；数据保留，不进入。 |
| 已过期 | EXPIRED | 订阅有效期过了。 | 登录后进入续费提示页，弹窗引导销售联系方式；工作台只读，不能新建/编辑任何单据。 |
| 待续费 | RENEW_PENDING | 有效期 15 天内到期。 | 登录后显示橙色续费提醒条。 |
| 初始化中 | INITIALIZING | 创建后正在执行初始化脚本（建 schema、写入基础档案），通常持续 30~90 秒。 | 登录提示「租户正在初始化，请稍后再试」。 |
| 已停用 | DEACTIVATED | 手动停用（长期不使用，非删除）。 | 登录提示「租户已停用」。 |
| 已删除（软删除） | DELETED | 软删除，数据保留 90 天，90 天后物理删除（可配置）。 | 不可见，登录提示「账号或密码错误」，避免泄露。 |

## 4. 租户管理（TenantManage 列表页）

### 4.1 功能说明

租户管理是平台运维的主页。核心能力：
- 搜索 + 筛选 + 分页浏览所有租户（支持 10 万级租户滚动列表）。
- 行内 8 个快捷操作：查看 / 编辑 / 续费 / 升级版本 / 冻结 / 解冻 / 停用 / 删除。
- 顶部 KPI 概览卡片（总数/本月新增/到期提醒/活跃数/冻结数/资源告警）。
- 顶部操作：新建租户 + 批量导入 + 批量冻结 + 批量续费 + 批量导 Excel。
- 快速筛选标签栏（4 种版本 × 8 种状态 = 32 个快速筛选组合）。

### 4.2 界面描述

#### 顶部 KPI 概览卡片（1 行 6 张彩色卡）
- 租户总数（蓝卡，大数字）。
- 本月新增（绿卡）。
- 30 天内到期（橙卡，点击后列表自动筛选到期日在未来 30 天内的租户 = 续费名单）。
- 当前活跃（=昨日有至少 1 个登录的 ACTIVE 租户，深绿卡）。
- 冻结/停用总数（红卡）。
- 资源告警租户（数据库连接池占比>80% 或 CPU/内存>80%，深红卡，点击跳部署管理筛选告警列表）。

#### 快速筛选标签栏
- **第一行版本 Tab**：全部 / 试用版 TRIAL / 标准版 STANDARD / 专业版 PROFESSIONAL / 企业版 ENTERPRISE。
- **第二行状态 Tab**：全部 / 激活 / 已过期 / 待续费 / 冻结 / 初始化中 / 停用 / 草稿。
- 两行 Tab 组合筛选，点击即生效。

#### 筛选区（`el-card`）
- 租户编号（精准输入，生成规则：`T-YYYYMMDD-NNNN`）。
- 企业名称（模糊搜索）。
- 统一社会信用代码（精准）。
- 管理员手机号/邮箱（模糊）。
- 行业分类（下拉：制造业/贸易/服务业/建筑/其他）。
- 规模（下拉：1-49人/50-199人/200-999人/1000人以上）。
- 到期日范围（`el-date-picker type=daterange`）。
- 创建时间范围。
- 查询 / 重置 + 「我的收藏」筛选方案下拉（同报表中心通用）。

#### 顶部操作按钮组（右端）
- **+ 新建租户**（主按钮，大蓝）→ 打开第 5 章的租户表单弹窗。
- **批量导入**（副按钮）→ 弹 Excel 导入向导，支持一次导入 100 家租户（模板下载→填→上传→校验→确认批量创建）。
- **批量冻结**（红副按钮）→ 需先多选行。
- **批量续费**（紫副按钮）→ 选行后批量续 1 月/3 月/1 年。
- **导出全部 / 导出筛选**（副按钮）→ Excel。
- **刷新**。

#### 租户列表表格（`el-table`）
**左固定列**（勾选框 + 租户编号 + 企业名称）+ 中间列 + **右固定列**（状态 + 操作）。

中间核心列：
- 企业 Logo 缩略图（40×40 圆角，无则显示公司首字）。
- 企业名称 + 简称 tag + 认证状态（已认证=蓝 √；未认证=灰）。
- 租户编号（可复制）。
- 订阅版本（彩色大 tag：TRIAL 灰 / STANDARD 蓝 / PROFESSIONAL 紫 / ENTERPRISE 金）。
- 启用模块包（多个蓝色小 tag 横排，如 销售/采购/库存，超过 3 个显示「+N」）。
- 行业/规模（标签）。
- 用户账号数（已用/配额，超配额数字红字）。
- 存储配额（GB，已用/总额，进度条，过 80% 橙）。
- 管理员账号（姓名 + 手机号/邮箱）。
- 有效期至（YYYY-MM-DD，≤ 15 天显示橙字，过期显示红字 + 已过期 icon）。
- 创建时间。
- 上次登录时间（昨日登录=蓝 tag，>7 天未登录=灰 tag，从未登录=—）。
- 资源告警状态（绿灯=正常 / 黄灯=注意 / 红灯=告警，无=未检测）。
- AuditColumns 审计列（创建人/创建时间/修改人/修改时间）。

**右固定列**（宽度 300）：
- 状态 tag（彩色：ACTIVE 绿/EXPIRED 红/FROZEN 红带锁/DEACTIVATED 灰/DRAFT 灰/RENEW_PENDING 橙/INITIALIZING 蓝带 loading）。
- 操作按钮组（link 按钮，根据状态动态显示/禁用）：
  - **所有 ACTIVE 及以上状态**都有：查看 / 编辑 / 续费 / 升级版本。
  - **ACTIVE** 额外有：冻结 / 停用 / 重置管理员密码 / 一键登录（=以管理员身份模拟登录进该租户，用于客服快速排错）/ 清空演示数据（TRIAL 转付费时用）。
  - **FROZEN** 额外有：解冻。
  - **EXPIRED / DEACTIVATED** 额外有：激活（=重新启用，同时要续费）。
  - **DRAFT** 额外有：立即初始化。
  - **非删除状态**末尾：删除（软删除）。

**底部分页**：`el-pagination` 20/50/100 条每页。

### 4.3 操作步骤

#### 新建租户（快速入口，完整流程见第 5 章）
1. 点右上「+ 新建租户」按钮。
2. 弹出第 5 章的租户表单弹窗。
3. 填写 → 保存 → 回到列表首行出现新租户。

#### 查看 / 编辑
- **查看**：点「查看」link → 同一表单弹窗（只读模式，所有输入框 disabled）。
- **编辑**：点「编辑」link → 表单弹窗可编辑；已激活租户的「企业库名（schema）」「数据库连接串」字段不可改（灰掉 + tooltip：已激活租户不可更改数据库配置）。

#### 续费操作
1. 目标租户行点「续费」link。
2. 续费弹窗：
   - 当前有效期至 = 只读展示。
   - 续费时长（`el-select`：1 个月 / 3 个月 / 6 个月 / 1 年 / 2 年 / 3 年 / 自定义日期）。
   - 续费方式下拉：现金支付 / 合同账期 / 赠送（赠送需填写赠送理由 + 赠费审批单号）。
   - 合同号（必填，现金/账期）。
   - 预计新的有效期至（自动计算 = 当前到期日 + 续费时长，若当前已过期则从今天+时长）。
   - 备注。
3. 二次确认弹窗（SUPER_ADMIN 输入登录密码 + 续费原因）→ 保存。
4. 列表中「有效期至」列值刷新 + 状态从 EXPIRED 自动变回 ACTIVE（若之前过期）。

#### 批量续费（月末集中续费）
1. 多选多个 30 天内到期的租户。
2. 点顶部「批量续费」紫按钮。
3. 弹窗：统一续费时长（如 1 年）+ 统一续费方式（如合同账期）+ 批量关联合同号 Excel（每行「租户编号 + 合同号」对应上传）。
4. 校验通过 → 执行 → 提示「成功 58 / 失败 2 / 失败详情：[...」。

#### 升级 / 降级订阅版本
1. 点「升级版本」link → 弹窗。
2. 选择新版本（TRIAL → STANDARD → PROFESSIONAL → ENTERPRISE，通常只升不降；降级需要 SUPER_ADMIN 再次输入密码）。
3. 版本变更后自动调整模块包（=新的版本默认模块包），可保留之前已开的附加模块（弹窗提供两个开关：「保留已有附加模块」Y/N、「追加新赠送的模块包」Y/N，默认都开）。
4. 关联合同号（必填）+ 变更原因。
5. 二次确认（SUPER_ADMIN 密码）→ 确认。
6. 保存成功后：
   - 用户数/存储配额立即生效（新版对应）。
   - 模块变更用户下次登录时生效（当前登录的用户需要重新登才看到新菜单项）。
   - 若从 PROF 降到 STAN，模块会自动隐藏（`VITE_HIDDEN_MODULES`）；降级前请确认客户已导出相关模块的历史数据。

#### 冻结 / 解冻 / 停用 / 激活
- **冻结（欠费/违规）**：点「冻结」→ 二次确认 + 原因（必填，下拉：欠费/违规/风控投诉/主动申请暂停）→ 状态变 FROZEN。
- **解冻**：FROZEN 行点「解冻」→ 输入解锁原因 → 回到 ACTIVE。
- **停用（长期暂停）**：ACTIVE 行点「停用」→ 状态变 DEACTIVATED（停用 = 服务下线，占资源比冻结少）。
- **激活**：EXPIRED / DEACTIVATED 行点「激活」→ 弹出续费弹窗（先续费再激活）。

#### 重置管理员密码
1. 点「重置管理员密码」link。
2. 敏感操作二次弹框：① 输入重置原因 ② 输入当前 SUPER_ADMIN 密码 ③ 勾选「我知晓重置后将以短信/邮件通知用户」。
3. 确认后系统生成 12 位随机强密码（数字+大小写+符号）。
4. 密码通过 2 种方式下发：① 短信给管理员手机 ② 邮件给管理员邮箱。
5. 管理员首次登录必须修改密码（强制修改密码弹窗）。

> **安全要求**：重置密码日志写入 `platform_audit_log`，永久可追溯。

#### 一键登录（模拟登录客户租户）
用于客服快速排错（不用问客户要密码）。
1. ACTIVE 行点「一键登录」link。
2. 弹二次确认（原因必填：如「客户 A 反馈销售订单保存失败需排查」）。
3. 新开浏览器标签页 → 自动以该租户 ADMIN 身份登录（左侧菜单显示当前身份 tag：「模拟登录（平台管理员）」，橙色）。
4. 操作完毕后在新标签点「退出模拟」→ 回到平台管理页。
5. **审计**：所有模拟登录的操作留痕（操作日志中操作者前缀：`SUPER_ADMIN-xxx 模拟登录`）。

#### 一键清空演示数据（TRIAL 转付费用）
1. 客户试用（TRIAL）后买付费版，其数据中可能包含演示数据（示例客户、示例订单、示例物料）。
2. 点行内「清空演示数据」link。
3. 弹框：勾选保留的非演示数据（如客户自己录入的客户/物料/订单）。系统自动识别「初始化标记=演示」的单据 + 演示标记的基础档案。
4. 二次确认（「我已确认演示数据识别范围」+密码）。
5. 执行后演示数据软删除（90 天可恢复）。

#### 删除租户（软删除）
1. 非删除状态的行点「删除」link。
2. 弹出危险操作三选框（必全部勾）：
   - □ 我已备份该租户的全部数据（数据库+文件存储）。
   - □ 我知晓删除后用户无法登录，且 90 天后物理删除不可恢复。
   - □ 我是本次操作的责任人，已填写下方原因。
3. 填删除原因 + 关联工单/合同号 + SUPER_ADMIN 密码。
4. 确认。
5. 状态变 DELETED（软删除）。90 天内可由运维在后台恢复；90 天后运行定时任务物理删除。

#### 批量冻结 / 批量导入
- **批量冻结**：多选 → 顶部「批量冻结」→ 原因 → 执行。
- **批量导入**：点「批量导入」→ 下载模板（含企业信息、版本、有效期、管理员信息等 20 字段）→ 填好上传 → 预校验（红黄绿行标记通过/警告/错误）→ 修正错误后点「确认创建」→ 系统批量初始化 schema + 发短信。

### 4.4 注意事项

- **演示数据清空误操作风险**：演示数据识别基于初始化时系统打在记录上的 `demo_flag=1`。如果客户自行复制了一条演示的客户档案再修改，可能也带着 `demo_flag=1`。清空之前请务必在保留清单中勾选或提前通知客户手动改。误清 = 90 天内可恢复（运维级恢复，走工单）。
- **模块降级的不可逆**：从 ENTERPRISE 降到 STANDARD 后，获客管理、生产、委外、CRM 等模块菜单立即隐藏。历史数据仍在数据库中（不会被删），但用户再看不到界面。降级前请提前导出相关模块历史台账。
- **续费与版本升级分别走不同审批**：
  - 续费（同版本延长时间）：TENANT_ADMIN 也能操作。
  - 版本升级/降级：必须 SUPER_ADMIN + 合同号 + 密码二次确认。
- **批量删除不支持**：没有批量删除操作（防止手抖）。真要批量删需走运维脚本 + 审批。
- **到期日自动提醒**：系统提前 30 天开始每日给平台销售发邮件提醒待续费名单（到 15/7/3/1 天也会再发一次）。列表中 RENEW_PENDING 状态的行即自动触发。
- **过期后宽限期**：默认配置过期后仍给 7 天只读宽限期（数据能查不能写），宽限期结束彻底冻结（连看都不能）。管理员可在系统参数调整「过期宽限期（天）」。

## 5. 新增/编辑租户（TenantForm 表单弹窗）

### 5.1 功能说明

TenantForm 是新增/编辑租户时弹出的大表单（900px 宽），内部 7 个 `el-steps` 步骤（或 7 个 `el-divider` 分块）。新建默认所有字段可填；编辑激活后租户时，敏感的「数据库配置」「租户编号」「创建账号」区块变为只读。

### 5.2 界面描述

弹窗（900px × 650px 内滚动）分 7 个分块：

#### ① 基本信息
- 租户编号（新建 placeholder：保存后自动生成；编辑只读）。
- 企业名称（必填，2~50 字）。
- 企业简称（必填，2~10 字，显示在系统顶部左上角 Logo 旁）。
- 统一社会信用代码（选填，18 位）。
- 行业分类（下拉，必填）。
- 规模（下拉，必填）。
- 所在地区（省市区三级级联，必填）。
- 详细地址（选填）。
- 企业 Logo（图片上传，<2MB，建议 200×200 透明 PNG）。
- 登录页背景图（<5MB，可选，不填用平台默认蓝天图）。
- 主题色选择（默认 `#1890ff` AntD 蓝，可自定义 6 个颜色方案按钮：蓝/绿/红/紫/橙/暗黑，+ 自定义取色器）。
- 企业简介（多行，选填，显示在对账单页脚等处）。

#### ② 订阅版本 & 模块
- 订阅版本（4 版 radio 按钮：试用版/标准版/专业版/企业版，切换时用户数和存储配额字段自动变更）。
- 版本到期日（日期选择器，必填；TRIAL 默认 = 今日 +30 天，其他版本用户填）。
- 用户数配额（`el-input-number`，根据版本默认：TRIAL=5、STANDARD=5、PROFESSIONAL=50、ENTERPRISE=不限 → 实际 ENTERPRISE 默认 9999）。
- 存储配额 GB（`el-input-number`，默认 TRIAL=2GB、STANDARD=10GB、PROF=100GB、ENT=不限）。
- 模块权限包列表（`el-checkbox-group` 多列 2~3 行）：
  - 灰色 disabled = 当前版本包含的基础包（必须开）。
  - 可勾 = 可选付费附加包。
- 关联合同号（TRIAL 选填，其他必填）。
- 合同到期日（选填）。

#### ③ 管理员账号
- 管理员姓名（必填）。
- 管理员手机号（必填，11 位格式校验，用于后续短信验证码/重置密码）。
- 管理员邮箱（必填，格式校验）。
- 初始密码（默认自动生成 12 位强密码，有「刷新换一个」「复制」「显示/隐藏」按钮；也可手动改，但要满足强度校验：≥12位+大小写+数字+符号）。
- 是否发送激活短信开关（默认开）。
- 是否发送激活邮件开关（默认开）。

#### ④ 部署配置（SUPER_ADMIN 专属，TENANT_ADMIN 只读）
- 部署模式（单选）：
  - 共享库（默认，STANDARD/PROFESSIONAL 默认）：多个租户共享同一 PostgreSQL 集群，靠 `tenant_id`/`schema` 隔离。
  - 独立库（ENTERPRISE 必选）：为该租户创建独立 PostgreSQL 数据库（schema = `tenant_${tenantNo}` 或自定义库名）。
- 数据库连接串（独立库时必填，共享库时 disabled = 默认平台连接池）。
- 对象存储（单选）：共享 OSS / 独立 OSS Bucket（ENT 可选）。
- 独立域名（选填）：支持绑定自定义域名，如 erp.customer.com。填写后生成 Nginx 配置申请单引导运维处理。
- 服务器区域（下拉：华东 1/华北 2/华南 1/海外新加坡等）。
- 资源配额（ENT）：CPU 核数（2/4/8/16/32）+ 内存 GB（4/8/16/32/64）+ 带宽 Mbps。

#### ⑤ 初始化选项
- 是否创建演示数据（switch，默认 TRIAL 开；付费版关）。开启后初始化脚本会写入：示例行业字典、示例 50 个物料、示例 20 个客户/供应商、示例销售/采购/生产单据各 10 条。便于客户快速体验。
- 初始化基础档案（switch，默认开）。勾选后初始化：
  - 默认角色（ADMIN/SALES/SALES_MANAGER/PURCHASE/PROD/WAREHOUSE/FINANCE/CUSTOMER_SERVICE）。
  - 默认审批流程（各单据标准模板一套）。
  - 系统参数默认值。
  - 字典项常用值。
  - 打印模板默认模板。
- 导入行业基础字典（可选，下拉：制造业通用/贸易通用/工贸一体/空白）。
- 币种设置（默认人民币 + 美元；可加欧元、日元等）。
- 本位币（默认 CNY）。
- 时区（默认 Asia/Shanghai）。

#### ⑥ 平台对接配置（可选）
- 是否启用企业微信 / 钉钉扫码登录（开关 + 应用配置）。
- 是否启用短信通道（默认开，平台默认短信通道）；ENT 可切到客户自己的阿里云短信账号。
- 是否启用邮件 SMTP（ENT 可自定义，其他用平台统一）。
- 是否启用第三方企业信息平台（获客模块对接企查查/天眼查的 key，ENT 可填客户自己的，其他共享平台额度）。

#### ⑦ 备注

备注多行文本。

弹窗底部操作按钮：「取消 / 保存（草稿）/ 保存并立即初始化」（新建时三按钮）；编辑模式：「取消 / 保存」。

## 6. 部署管理（DeployManage）

### 6.1 功能说明

部署管理是平台运维的「实时监控 + 运维工具箱」。面向 TENANT_ADMIN / SUPER_ADMIN，主要能力：
1. 租户列表 + 资源概览（CPU/内存/连接池/存储 4 个维度的使用率/阈值）。
2. 全局拓扑搜索筛选（按告警状态/版本/区域/部署模式）。
3. 行内 6 个运维工具箱：重启租户服务、清理缓存、重建搜索索引、导出诊断包、查看实时日志、数据库连接检测。
4. 资源告警详情弹框（点击红灯/黄灯展开）。
5. 全局顶部 4 个平台级 KPI 卡（平台所有租户合计资源占用）。

### 6.2 界面描述

#### 顶部平台级 KPI 卡
- 平台总 CPU 使用率（%，双轴）。
- 平台总内存使用（GB，已用/总额）。
- 平台总对象存储使用（TB）。
- 平台总数据库连接池占用率（%）+ 告警租户数量。

#### 筛选卡
- 告警状态（全部/正常/注意/告警）。
- 区域（华东/华北/华南/海外）。
- 部署模式（共享/独立）。
- 版本（4 版）。
- 租户名称/编号模糊搜。
- 查询 / 重置。
- 右按钮：「导出所有租户资源使用报告」/「查看平台资源告警历史」。

#### 租户资源表格
左固定列 = 编号+名称；右固定 = 操作列。中间资源列：
- 部署模式（独立=金色标签；共享=蓝色）。
- 区域（小 tag）。
- CPU 使用率：进度条（绿<60 / 橙 60-80 / 红>80）。
- 内存使用率：进度条。
- 存储使用率：进度条（独立库显示 GB 数，共享显示当前租户 bucket 用量）。
- DB 连接池使用率：进度条（连接池占用/总连接数）。
- 最近一次告警时间（若有，红字；若无=—）。
- 当前在线用户数（近 5 分钟登录的用户数）。
- 服务运行状态：绿色「运行中」+ 运行天数 / 灰色「已停止」。
- 综合状态灯列：绿 / 黄 / 红 圆点。

#### 操作列（右固定，280px）
6 个工具按钮（link 或图标按钮）：
1. **重启租户服务**（橙图标）→ 二次确认（原因+密码，ENT 独立部署=重启独立 Pod；共享库租户=清理内存并强制刷新权限缓存）。
2. **清理缓存**（蓝图标）→ 清理该租户的 Redis 缓存（权限、字典、参数）。
3. **重建搜索索引**（黄图标）→ 对 ElasticSearch 的租户索引做全量重建（数据量大时耗时 5~30 分钟）。
4. **导出诊断包**（灰图标）→ 后台打包「系统参数配置 + 最近 7 天日志 + 慢 SQL TOP 50 + 当前资源使用快照」→ 异步任务，完成后消息中心下载 ZIP。
5. **查看实时日志**（绿图标）→ 打开 30 秒 WebSocket 实时日志弹框（类似 `tail -f`，按 TRACE/DEBUG/INFO/WARN/ERROR 等级筛选）。
6. **数据库连接检测**（数据库图标）→ 执行 10 次连接探测 + 平均响应时间，弹出检测报告（用于判断 DB 是否慢）。

#### 资源告警详情弹框
点击综合状态灯的红/黄圆点 → 弹框显示：
- 告警时间列表（多条）。
- 告警类型：CPU/内存/存储/连接池。
- 阈值与实际值（例：连接池阈值 80%，实际 92.3%）。
- 持续时间。
- 已自动触发的处理动作（如：已自动清理缓存 / 已自动水平扩展 Pod，ENT 才有）。
- 推荐人工处理动作。
- 「一键处理」按钮（对 CPU/内存高 = 自动扩容 Pod，ENT；对连接池高 = 自动杀空闲连接；共享库模式下只能告警，需人工判断）。

### 6.3 操作步骤

#### 日常巡检（平台运维每日 3 次）
1. 打开部署管理页，看顶部 4 张 KPI 卡：
   - CPU 连续 > 70% → 告警。
   - 总内存 > 80% → 告警。
   - 连接池 > 75% → 告警。
2. 右上筛选「告警状态=告警/注意」→ 查看租户列表。
3. 点红灯 → 查看告警详情：
   - 若 = 连接池高 → 先点操作列「清理缓存」→ 30 秒后看是否降；仍高 → 点「数据库连接检测」看慢 SQL → 导出诊断包发给 DBA。
   - 若 = CPU/内存高（ENT）→ 弹框里点「一键处理」= 自动扩容。
   - 若 = 存储 > 95% → 通知客户清理附件/升级存储，或在编辑租户中加大存储配额。
4. 每 4 小时重复一次。

#### 手动重启租户服务
1. 客户反馈「页面卡顿/菜单不更新」，但其他租户正常。
2. 找到对应租户 → 操作列点「重启租户服务」。
3. 二次确认：原因 + SUPER_ADMIN/TENANT_ADMIN 密码。
4. 重启期间（通常 10~30 秒），该租户用户请求会短暂 503，稍后自动恢复。
5. 完成后 ElMessage 提示「重启成功」，服务状态仍「运行中」但运行天数归零。

#### 清理缓存（配置变更后立即生效）
1. 平台管理员改了角色权限/字典项/系统参数后，租户侧需要缓存刷新。
2. 点「清理缓存」→ 无二次确认（低风险）→ 5 秒完成 → 提示「缓存已清理」。
3. 若租户用户仍看到旧数据 → 建议用户重新登录。

#### 重建搜索索引（搜索不到数据时）
1. 列表页搜索明明存在的单却搜不到（常见于：数据库迁移后、大导入后、版本升级后）。
2. 点「重建搜索索引」→ 二次确认（原因）。
3. 弹窗显示进度条（0~100%）。共享库租户通常 1~5 分钟；ENT 大数据量 30 分钟。
4. 进度条到 100% 后关闭弹框 → 重试搜索。

#### 导出诊断包（提给供应商/实施顾问排查问题）
1. 客户反馈问题需要平台提供诊断信息。
2. 点「导出诊断包」→ 立即生成后台任务。
3. 通常 1 分钟内，右上角消息中心「我的任务」提示「诊断包导出完成」。
4. 点击消息下载 ZIP。包内容包括：
   - `01-snapshot/`：资源快照 JSON。
   - `02-logs/`：最近 7 天 INFO 以上日志 + 最近 1 天 DEBUG。
   - `03-sql-top50/`：慢 SQL 排名（按累计耗时降序）。
   - `04-config/`：非敏感系统参数配置清单（加密字段已脱敏）。
   - `MANIFEST.md`：清单说明 + 导出版本号 + 导出时间。

#### 查看实时日志
1. 点「查看实时日志」→ 弹出 WebSocket 实时日志框。
2. 顶部筛选框：日志级别（默认 INFO+WARN+ERROR）、关键词（如 NullPointerException）。
3. 实时滚动显示，底部显示连接状态（绿=已连接；红=断开自动重连）。
4. 复制关键错误 → 排查。
5. 30 秒自动停止（避免长时间占用连接）。需要继续点「继续接收」。

### 6.4 注意事项

- **重启租户 ≠ 重启整个平台**。共享库模式下，重启租户 = 仅清理该租户的上下文、权限缓存、强制所有该租户用户下一次请求重新拉权限。不会影响其他客户。只有 ENT 独立部署模式下，重启才是真正重启 Pod。
- **重建搜索索引高 CPU**。执行期间该租户可能出现 5~10 分钟搜索慢或暂时无结果状态；建议在低峰期（夜间/周末）做。
- **清理缓存不影响业务数据**。只清缓存，不清数据库；风险极低，但频繁清理会让缓存命中率下降、DB QPS 瞬间升高（每秒 10 次以内是安全的）。
- **诊断包不含明文密码**。所有密码、密钥、Token 字段都会被 `***` 脱敏，可安全发给实施顾问。
- **WebSocket 长连接断开**。实时日志页面如果 30 秒内无操作会自动断开（安全+资源节省）。需要长期看日志建议走服务器上文件 `tail -f`。
- **共享库模式下的存储告警**。存储进度条显示的是该租户在共享对象存储中的用量（约等于：上传的附件+图片+PDF+Excel 导出历史）。超过 90% 会在后台通知销售联系客户升级。

## 9. 附录：常见问题

### Q1：租户创建后一直卡在 INITIALIZING，超过 2 分钟？
A：常见原因按概率：
1. **数据库连接失败**：独立库模式下，自定义连接串写错/IP 白名单没加。回到编辑，检查连接串。
2. **文件服务（OSS）不可用**：上传初始化模板依赖对象存储。部署管理页看平台级存储告警。
3. **初始化脚本本身异常**（建表 SQL 语法错）。
4. 处理：部署管理 → 对应租户 → 导出诊断包 → 查看 `02-logs/` 中的 `init-task.log`。若无法解决，联系研发。

### Q2：租户 ACTIVE 状态但客户登录提示「租户已冻结」？
A：检查 3 点：
1. 列表状态到底是 ACTIVE 还是 FROZEN？（可能看错行）。
2. 到期日是否已过期 + 宽限期是否也过了？宽限期内状态仍显示 ACTIVE（橙色待续费 tag），但功能已只读。宽限期结束，系统凌晨 3 点定时任务会把状态自动变 EXPIRED/FROZEN。
3. 是否有风控规则触发（如客户 IP 来自高风险地区，自动冻结）？在「租户详情 → 风控记录」页查看（若开启）。

### Q3：从 TRIAL 升级到付费版后，演示数据忘了删，能补删吗？
A：能。列表行「清空演示数据」按钮任何状态都能按，只要该租户初始化时打了 demo_flag。执行之前请先与客户确认「哪些是他们自己录入的真实数据」，避免误删。

### Q4：客户要求独立域名，流程怎么走？
A：6 步：
1. 在 TenantForm ④ 部署配置里的「独立域名」栏填客户期望域名（如 `erp.abc.com`）。
2. 保存表单后系统自动生成工单「申请配置独立域名」，指派给运维。
3. 运维在 Nginx 配置新增 `server_name erp.abc.com`，HTTPS 证书（自动 LetsEncrypt 或客户提供）。
4. 运维邮件通知客户：请将该域名 CNAME 解析到平台指定的 LB 地址。
5. 客户在自己的域名服务商处加 CNAME 记录。
6. 10 分钟后刷新 DNS → 浏览器访问 `https://erp.abc.com` 验证 OK → 关闭工单。

### Q5：模块包关闭后，历史数据在哪？
A：数据仍在租户的数据库中，只是前端路由/菜单隐藏。需要临时看：
1. 联系 SUPER_ADMIN 把模块暂时打开（客户导出历史数据）。
2. 或者在报表中心导出该模块完整历史台账（即使菜单关了，报表中心的导出权限可由 SUPER_ADMIN 为客户临时开一个「只读导出账号」）。

### Q6：租户删除了还能恢复吗？
A：90 天内可运维级别恢复（数据库 `deleted=1` 标记仍在，定时任务 90 天才物理清）。超过 90 天的只能从备份恢复。备份保留期 = 最后一次备份后 180 天。

### Q7：SUPER_ADMIN 账号的密码忘了怎么办？
A：SUPER_ADMIN 不能通过「忘记密码」自助重置（防止被钓鱼）。需要 2 个步骤：
1. 部署服务器上执行 `bin/reset-super-admin.sh` 脚本 → 需要 Linux root 权限 + 填写安全问题。
2. 脚本重置后，生成临时密码发送到注册时的安全邮箱。
3. 首次登录强制修改。安全提示：SUPER_ADMIN 的密码建议用 1Password 等密码管理器，严禁多人共用。

### Q8：客户要迁到私有化部署，怎么导出所有数据？
A：企业版客户可以申请「私有化部署迁移包」。流程：
1. 签迁移合同/补充协议（确定范围、交付时间）。
2. SUPER_ADMIN 在部署管理 → 导出诊断包（包含配置快照）+ 「全量数据导出任务」（生成 CSV/SQL dump 加密包）。
3. 研发配合：去平台化（去掉 SaaS 特有字段）+ 适配私有化的部署脚本。
4. 交付：通过加密网盘交付给客户 IT，客户部署后在私有化环境验证数据完整性。
