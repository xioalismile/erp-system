## 2. 本轮发现并修复的问题

| # | 问题 | 影响 | 修复 |
|---|---|---|---|
| 1 | `npm run test` 必失败：Vitest 默认规则把 `tests/` 下的 Playwright 用例当单测加载，12 个文件报 `test.describe()` 错误 | 单测命令无法作为发版闸门 | `vite.config.js` 增加 `test.exclude: ['**/node_modules/**','**/dist/**','tests/**']`（不能用 `**/tests/**`，会把 `src/tests` 一起排除） |
| 2 | 销售报表中心「年度目标完成率」仪表盘空白 | 图表不渲染，控制台报 `Series gauge is used but not imported` | `src/utils/echartsCore.js` 补登记 `GaugeChart`；实测 4 个图表画布齐全、0 报错 |
| 3 | 工位看板接口 500：`WorkstationController.dashboard` 对 `select("DISTINCT workstation_type")` 的结果直接 `map(getWorkstationType)`，空值行被 MyBatis 映射成 null 元素 → NPE | 工位页面统计卡报错 | 流上先 `filter(Objects::nonNull)`；实测接口 `code=200`，统计正常 |
| 4 | 成本核算同类隐患：`select("DISTINCT material_id")` 后遍历未判空 | 期间内有非物料流水时可能 NPE | 循环内 `t != null` 判空 |
| 5 | 字段权限分页键查询同类隐患：`select("page_key")` 后 `stream().map()` 未判空 | 存在 page_key 空行时可能 NPE | 先过滤 null 元素 |
| 6 | AI 小助手对“无关键词/英文/问候”输入回“上下文空间已用完” | 管理员账号工具清单 438 个 ≈ 112k tokens，关键词零命中回退全量 → 直接撑爆 128k 上下文，助手不可用 | 增加工具清单预算保护：装不下时降级为“常驻工具 + 常驻查询 + 全部只读 query_*”；实测英文查订单、中文问候均正常，占用 64–70k |
| 7 | 物料档案「主图」选择不落值：`ImageUploader` 用 `:main-image.sync`（Vue 2 语法），Vue 3 不支持 `.sync`，`update:mainImage` 事件被忽略 | 用户选主图后保存丢失 | 改为 `v-model:main-image`，并修正组件注释里的错误示例 |
| 8 | `BillActions` 审批人缓存用了 `_approverCache`：Vue 3 不代理 `_` 开头的 data 键 | 缓存失效（重复查询，功能不报错） | 改名 `approverCache` |
| 9 | 物料列表 `el-image` 重复写 `preview-teleported`（属性 + 绑定） | Vue 编译告警 | 去掉重复绑定 |
| 10 | `Login.vue` 是全项目唯一 `<script setup lang="ts">`，混入 `e: MouseEvent`、`as any` 等 TS 语法 | `npm run lint` 解析报错；与全项目 JS 约定不一致 | 去掉 TS 语法改回 JS |
| 11 | 冒烟测试登录助手按文本点「登 录」可能点到隐藏布局副本（登录页是缩放画布 + 双布局） | `test:smoke` 无法登录 | 改为直接触发表单 `requestSubmit()`，保留点击兜底 |

**附带清理**：`src/i18n/glossary.js` 有 27 个重复词条（同一中文键写了两次，后值静默覆盖前值），已删除前值、保留当前生效的后值，行为不变，`no-dupe-keys` 清零。
