# 02 系统设置（设置中心）测试用例

## 范围与风险点

- 覆盖：基础信息、系统参数、角色权限、员工权限、数据维护、语言；库存/CRM 预警、收付价策略、提成率、物流、自动下推；菜单名称、主题、界面尺寸、消息通知、自动编号、审批、批次编号、打印、自定义字段；操作日志；AI 设置。
- 风险一：开关改了但单据页面没跟着变（两处口径各写一遍）。
- 风险二：权限改动不即时生效（需重登才算）。
- 风险三：设置改动影响历史单据（应按"新单生效、老单不变"）。

**所有开关类用例固定三查**：改前页面表现 → 改后页面表现 → 改回原值后恢复。

## 一、审批设置

菜单「设置中心 → 审批设置」。

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-001 | P0 | 「其他入库单」审批关闭 | 新建其他入库单 → 提交 | 提示"提交成功，单据已生效"，状态直接「已生效」，无审批节点 |
| SZ-002 | P0 | 打开「其他入库单」审批 | 新建 → 提交 | 提示"已提交审批"，状态「待审核」；审核按钮出现；审核后变「已生效」 |
| SZ-003 | P1 | 审批关闭 | 审批中心/待办中 | 不出现该单据的待办；提交过的单不产生审批任务 |
| SZ-004 | P1 | 审批开启且单据待审核 | 重置草稿 | 被拦，提示先由审批人处理或驳回 |
| SZ-005 | P1 | 审批开关来回切 | 切回关闭 → 再新建提交 | 恢复杂为"提交即生效"，历史待审核单不受影响 |
| SZ-006 | P2 | 审批流程配置了多节点 | 提交后逐节点审批 | 每个节点审批人正确；全部通过才「已生效」；任一驳回回「已驳回」 |

## 二、含税 / 外币总开关

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-007 | P0 | 关闭「启用含税业务」 | 打开销售订单/采购入库 | 表头无「计税方式」，明细无税率/税额列；合计=数量×单价，税额 0 |
| SZ-008 | P0 | 打开含税 | 同上 | 税率列出现，默认税率取设置；税额=金额×税率，误差≤0.01 |
| SZ-009 | P0 | 关闭「启用外币」 | 新建销售订单 | 币种锁定本位币、汇率只读为 1；切币种不可选 |
| SZ-010 | P0 | 打开外币 | 同上 | 币种可选美元等；选外币后汇率自动带出，可修改 |
| SZ-011 | P1 | 外币关闭时打开一张历史外币单 | 查看 | 历史单据保持原币与汇率，不被改成本位币 |

## 三、单据号规则（自动编号）

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-012 | P0 | 其他入库单编号规则：前缀 `OR-`、日期 `yyyyMMdd`、序号 4 位 | 新建其他入库单 | 单号形如 `OR-20261127-0001`，与规则一致 |
| SZ-013 | P0 | 同上，已有 0001 | 再建两张 | 依次 0002、0003，不跳号不重复 |
| SZ-014 | P1 | 改规则前缀为 `RK-` | 新建单据 | 新单用 `RK-`；历史单号不变 |
| SZ-015 | P0 | 任意单据 | 保存 → 再保存 → 提交 → 刷新 | 单号全程不变（本次缺陷回归点） |
| SZ-016 | P1 | 关闭"自动生成" | 新建单据 | 单号输入框可手工填；不填提交被拦并提示 |
| SZ-017 | P2 | 手工填一个已存在的单号 | 保存 | 若"单据号查重"开启 → 被拦；关闭 → 允许保存 |

## 四、批次编号设置

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-018 | P0 | 批次规则：前缀空、日期 YYMMDD、序号 4 位、自动生成开 | 采购入库选批次物料 | 批次号自动带出形如 `261127-0001`，不重复 |
| SZ-019 | P1 | 关闭"自动生成" | 同上 | 批次号为空，需手填；不填提交被拦 |
| SZ-020 | P1 | 关闭"允许修改批次号" | 打开已保存单据改批次号 | 批次号只读，保存无效或提示不允许修改 |
| SZ-021 | P1 | 「允许批次货品重复入库」关闭 | 同一物料同一批次入库两次 | 第二次被拦，提示批次已存在；开启后可累加 |
| SZ-023 | P2 | 批次规则改前缀 `B-` | 新建单据选批次物料 | 新批次号带 `B-` 前缀；历史批次号不变 |

## 五、角色权限 / 字段权限

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-024 | P0 | 新建角色「仓管」，只勾库存菜单 | 用该角色登录 | 侧边栏只有库存菜单；直接输销售订单地址被拦到 403 或工作台 |
| SZ-025 | P0 | 角色未勾「其他入库单」 | 直接访问 `/inventory/other-receipts` | 不能进入；不出现"页面打开了但接口 403 一串报错" |
| SZ-026 | P0 | 角色关闭物料「成本」字段 | 用该角色看即时库存、物料列表、导出 Excel、打印 | 四处均无成本列/值（口径一致） |
| SZ-027 | P1 | 角色关闭「删除」按钮权限 | 打开单据 | 删除按钮不显示；直接调删除接口被后端拦住 |
| SZ-028 | P1 | 修改角色权限后不重登 | 当前会话内切页面 | 权限变化即时生效（或明确提示需重新登录，不能表现不一致） |
| SZ-029 | P2 | 员工权限补充 | 给某员工单独加一个菜单 | 该员工登录后多出该菜单；其他同角色员工不受影响 |

## 六、自定义字段 / 菜单名称 / 界面

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|

| SZ-031 | P1 | 同上，字段勾「可搜索」 | 其他入库单列表 | 搜索区出现该字段筛选；按值筛选生效 |

| SZ-034 | P2 | 界面尺寸改为"宽松" | 任意列表页 | 行高/字号按设置变化；刷新后保持 |

## 七、消息通知 / 打印 / 自动下推 / 操作日志

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| SZ-035 | P1 | 打开审批通知 | 提交一张需审批的单 | 审批人铃铛收到通知；点开可跳到该单据 |
| SZ-036 | P1 | 打开库存预警 | 物料库存低于安全库存 | 预警设置页/铃铛出现预警；关闭开关后不再产生 |
| SZ-037 | P1 | 打印模板绑定「其他入库单」 | 单据详情点打印 | 预览字段完整、金额格式正确；打印后原单据不变 |
| SZ-038 | P1 | 自动下推开启（某链路） | 源单审核 | 自动生成下游草稿单；来源单关联正确；关闭后不再自动生成 |
| SZ-039 | P1 | 操作日志 | 保存、提交、审核一张单 | 日志按时间倒序记录操作人/时间/动作；能看字段变更前后值 |
| SZ-040 | P2 | 数据维护 | 执行一次数据维护/清理类操作 | 有二次确认；执行结果有明确反馈；不误删在用数据 |

## 本模块最可能出问题的一条

**SZ-007 / SZ-008（含税开关）与 SZ-009 / SZ-010（外币开关）**：这两个总开关同时影响单据列、明细计算、打印模板三处，历史上出现过"明细税额为 0 但合计仍带税"的口径不一致。验证时用一张两行不同税率的单，切换开关前后各保存一次，逐列对金额。
