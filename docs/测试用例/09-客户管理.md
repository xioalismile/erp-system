# 09 客户管理（CRM）测试用例

> 说明：按用户要求，CRM 模块内的「报表中心」页不在本次范围。

## 范围与风险点

- 覆盖：我的驾驶舱、销售目标、销售过程、销售预警、我的私海、公海池、销售线索、商机管理、销售漏斗、联系人、跟进记录、客户投诉、满意度调查。
- 风险一：公海/私海的领取、回收、保护期规则（谁能在什么时候看到、领走）。
- 风险二：线索 → 客户 → 商机的转换是否保留原数据与归属。
- 风险三：跟进提醒与预警按"多久没跟进"触发，时间口径容易错。
- 风险四：销售只能看到自己的数据（数据权限），越权接口是否被拦。

## 一、我的私海 / 公海池

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CRM-001 | P0 | 销售A 名下有 1 个客户 | 用 A 登录打开「我的私海」 | 只看到自己的客户；看不到销售B 的客户 |
| CRM-002 | P0 | 公海有客户 | A 领取该客户 | 客户从公海消失、出现在 A 的私海；归属=A |
| CRM-003 | P0 | A 刚领取 | 用 B 查看公海 | 该客户已不在公海（不能被两人同时领取） |
| CRM-004 | P1 | 客户有保护期（如 30 天未跟进回收） | 超过保护期不跟进 | 自动回收进公海（或预警）；回收后 A 的私海不再显示 |
| CRM-005 | P1 | 私海客户 | A 主动释放到公海 | 客户进公海、归属清空；历史跟进记录保留 |
| CRM-006 | P1 | 无 CRM 权限的角色 | 直接调公海领取接口 | 被后端拦截（403），不是仅前端隐藏按钮 |

## 二、销售线索 / 商机 / 漏斗

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CRM-007 | P0 | 无 | 新建线索：公司名、联系人、来源 → 保存 | 保存成功；列表可见；归属当前用户 |
| CRM-008 | P0 | 线索已存在 | 转换线索为客户 | 生成客户档案，线索标记"已转化"；原联系人、电话带入客户 |
| CRM-009 | P0 | 有客户 | 新建商机：客户、金额、预计成交日期 | 保存成功；商机与客户关联 |
| CRM-010 | P1 | 商机在「初步接洽」 | 推进到「报价」→「成交」 | 阶段按顺序推进；漏斗图各阶段数量同步 |
| CRM-011 | P1 | 商机已成交 | 从商机生成销售订单（如支持） | 客户、金额带入订单；来源单关联正确 |
| CRM-012 | P2 | 商机阶段直接跳到最后 | 提交 | 按系统允许或给出限制提示（口径统一） |

## 三、跟进 / 预警 / 销售目标

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CRM-013 | P0 | 有客户 | 新增跟进记录：方式、内容、下次跟进时间 | 保存成功；客户详情能看到跟进时间线 |
| CRM-014 | P1 | 下次跟进时间已过 | 打开提醒/预警页 | 出现该客户提醒；完成跟进后提醒消失 |
| CRM-015 | P1 | CRM 预警设置：X 天未跟进 | 构造 X+1 天未跟进 | 预警列表出现该客户；X 天内不出现 |
| CRM-016 | P1 | 设置销售目标：本月 10 万 | 新增成交 3 万 | 目标完成度 30%；跨月后重新计算 |
| CRM-017 | P2 | 无跟进记录的客户 | 客户详情 | 时间线空态提示，不报错 |

## 四、联系人 / 投诉 / 满意度

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CRM-018 | P1 | 有客户 | 新增联系人并设为主联系人 | 客户详情显示主联系人；再设另一个为主，原主自动取消 |
| CRM-019 | P1 | 有客户 | 新增客户投诉：类型、内容、责任人 | 保存成功；处理后可填处理结果并关闭 |
| CRM-020 | P1 | 投诉关闭 | 反审/重新打开 | 状态与处理时间正确；不允许重复关闭 |
| CRM-021 | P1 | 有客户 | 发起满意度调查 → 填写评分 | 结果按问卷汇总；分数与选项一致 |
| CRM-022 | P2 | 调查无回复 | 查看统计 | 显示未回复数，不报错 |

## 五、我的驾驶舱

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CRM-023 | P1 | 销售A 有客户/商机 | 打开驾驶舱 | 卡片数值与私海/商机数据一致；点击卡片能穿透到对应列表 |
| CRM-024 | P2 | 新用户无数据 | 打开驾驶舱 | 全 0 或空态，不报错不白屏 |

## 本模块最可能出问题的一条

**CRM-002 / CRM-003（公海领取的并发与可见性）**：领取动作若没有服务端唯一约束，两个销售同时点会都显示"领取成功"，之后跟进记录挂错人。验证时用两个浏览器窗口同时领取同一客户，确认只有一个成功、另一个给出明确提示，且客户归属唯一。
