# 01 基础资料 测试用例

## 范围与风险点

- 覆盖：计量单位、币种、结算方式、银行账户、价格等级、部门、员工、仓库、货位、物料分类、物料、客户、供应商、BOM、质检模板。
- 风险一：主数据被单据引用后仍可删/改关键字段 → 历史单据显示错乱。
- 风险二：编码重复、编码规则与手工输入冲突。
- 风险三：停用数据仍出现在下拉里；停用后历史单据能否正常显示。
- 风险四：字段级权限（成本、采购价）在列表、详情、导出、打印四处口径不一致。

## 一、计量单位

前置：无。菜单「基础资料 → 计量单位」。

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| JC-001 | P0 | 无 | 点「新增」→ 填 单位编码 `PCS`、单位名称「个」、小数位 0 → 保存 | 列表首行出现 `PCS 个`；再次点新增并保存，编码不变（不换号不重复） |
| JC-002 | P0 | 无 | 新增时不填单位编码，只填名称 → 保存 | 若编码规则开启自动生成：编码按规则生成；若未开启：提示"单位编码不能为空"，不落库 |
| JC-003 | P0 | 已有 `PCS` | 新增再用编码 `PCS` → 保存 | 提示"单位编码已存在"（或等价文案），列表不出现第二条 `PCS` |
| JC-004 | P1 | 无 | 单位名称填 60 个汉字 → 保存 | 按字段长度限制截断或提示超长；不出现数据库报错弹窗 |
| JC-005 | P1 | 已有「个」 | 修改名称「个」→「件」→ 保存 → 打开一张引用该单位的物料 | 单位档案变为「件」；物料明细显示「件」；历史单据明细仍能打开不报错 |
| JC-006 | P0 | 单位「个」已被物料 A 引用 | 删除「个」 | 被拦截，提示"已被物料引用"，单位仍在列表 |
| JC-007 | P1 | 单位「PCS」未被引用 | 删除 | 删除成功，列表不再出现；刷新后仍不存在 |
| JC-008 | P1 | 已有「个」 | 停用「个」→ 新建物料选单位 | 停用单位不出现在下拉；物料列表编辑页不报错 |
| JC-009 | P1 | 单位列表有 30 条以上 | 搜索框输入 `PCS` → 回车；再点重置 | 只显示匹配行；重置后恢复全量；分页从第 1 页开始 |
| JC-010 | P2 | 无 | 连续两次快速点「保存」 | 只生成一条数据，无重复行 |
| JC-011 | P2 | 无 | 单位小数位填 `-1` / `10` | 给出范围限制提示或自动纠正，不允许负数写入 |

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |

## 本模块最可能出问题的一条

**JC-030 / JC-031（批次列按物料显隐）**：批次功能刚改为只认物料档案，历史上"开批次但没批次号"的数据与新口径交叉，最容易出现"列显示了但提交被拦"或"列没显示却要求必填"。验证时必须在同一张单里同时放一个批次物料和一个非批次物料，确认列按行出现、提交一次通过。
