## 二、系统说明

### 角色字段说明

| 字段              | 作用               | 是否前端展示     |
| --------------- | ---------------- | ---------- |
| role\_code      | 业务身份标识，代码权限判断依据  | 是          |
| role\_name      | 角色名称             | 是（点击可编辑权限） |
| role\_type      | 已废弃（仅分类标签，无权限逻辑） | 否          |
| is\_system      | 是否系统内置(1=不可删)    | 否          |
| data\_scope     | 数据权限范围           | 是          |
| sys\_role\_menu | 功能菜单权限           | 通过弹窗维护     |

## 三、踩坑记录

1. **role\_type 是伪字段**：后端无任何基于 role\_type 的权限判断，纯展示标签，前端已移除
2. **权限回显**：打开权限弹窗必须调 getRole 拿已有 menuIds 并 setCheckedKeys，否则用户每次都要重选
