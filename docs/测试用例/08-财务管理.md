# 08 财务管理 测试用例

## 范围与风险点

- 覆盖：销售预收款单、采购预付款单、收款单、付款单、费用分摊、成本核算、成本核算配置、工序工资核算。
- 本项目口径（按此断言）：
  - 收付款审核**不动银行账户余额**，只更新核销明细与应收应付/预收预付余额。
  - 应收应付不自动生成；销售按配置生成收款单草稿。
  - 成本核算单**只能由"当期核算"生成**，无手工新增入口。
  - 费用分摊按表头分摊方式拆到来源入库单的每一行物料。
- 风险一：费用分摊一个金额被记到每个物料（重复计入）。
- 风险二：分摊基数（数量/金额）取错行或取整张单。
- 风险三：收款核销后应收余额没减、或反审后没恢复。
- 风险四：成本核算重复归集（同一单据被算两次）。

## 一、预收款 / 预付款

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CW-001 | P0 | 有客户 | 新建销售预收款：客户A、金额 5000 → 提交审核 | 状态正确；客户预收余额 +5000 |
| CW-002 | P0 | 接上 | 反审 | 预收余额回 0 |
| CW-003 | P1 | 有预收款 | 销售订单/发票核销预收 | 应收减少、预收余额相应减少；金额不为负 |
| CW-004 | P0 | 有供应商 | 新建采购预付款：供应商 3000 → 审核 | 预付余额 +3000；反审回 0 |
| CW-005 | P1 | 预付款已核销 | 反审 | 被拦，提示已核销 |

## 二、收款单 / 付款单

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CW-006 | P0 | 客户有应收 1130 | 新建收款单：客户A、金额 1130、核销发票 → 审核 | 应收余额 0；核销明细显示该发票；**银行账户余额不变**（本项目口径） |
| CW-007 | P0 | 接上 | 反审收款单 | 应收恢复 1130；核销明细撤销 |

| CW-009 | P1 | 收款金额超过应收 | 提交 | 被拦或转为预收（按系统口径记录）；不允许应收变负数 |
| CW-010 | P0 | 供应商有应付 565 | 新建付款单 → 审核 | 应付余额 0；银行账户余额不变 |
| CW-011 | P1 | 付款单已审核 | 反审 | 应付恢复 |
| CW-012 | P2 | 收款单草稿 | 删除 | 应收不变 |

## 三、费用分摊

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CW-013 | P0 | 生产入库两行：G10001 10@10=100、G10002 30@10=300（已生效） | 新建费用分摊：费用行「人工费用」400、分摊方式「按金额分摊」、分摊对象选该入库单 → 自动分摊 → 保存 → 提交 → 审核 | 保存一次即产生一张单（**再点提交不新建第二张**）；分摊比例 100%、分摊金额 400 |
| CW-014 | P0 | 接上 | 打开成本核算做「当期核算」→ 看这两行物料 | 直接人工 G10001 **100**、G10002 **300**（按金额拆分，不是各记 400） |
| CW-015 | P0 | 另一张入库：G10004 10@30=300、G10005 30@3.3333=100 | 费用分摊 400「制造费用」「按数量分摊」→ 审核 → 当期核算 | 制造费用 G10004 **100**、G10005 **300**（按数量 10:30，与金额比例相反） |
| CW-016 | P1 | 分摊按「平均分摊」两行 | 同上 | 两行各 200 |
| CW-017 | P1 | 分摊对象类型 | 选采购入库单 | 落库的「分摊对象类型」应为采购入库单（不能永远是生产入库单）；审核后能归集到采购入库的两行 |
| CW-018 | P1 | 分摊明细不填对象或金额为 0 | 保存 | 被拦或该行被过滤，不产生 0 金额成本行 |
| CW-019 | P1 | 费用分摊单已审核 | 反审 | 对应的成本明细被撤销；成本核算重算后不再包含该金额 |
| CW-020 | P2 | 费用类型选「出差/快递」等期间费用 | 审核 | 不归集产品成本（成本核算中无对应行） |
| CW-021 | P2 | 分摊金额合计 ≠ 费用合计 | 保存 | 提示差额并阻止保存 |

## 四、成本核算

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CW-022 | P0 | 当月有已生效入库/领料/分摊 | 「当期核算」选期间 → 确认核算 | 生成/更新每个物料一行；无新增入口（列表页没有"新增"按钮） |
| CW-023 | P0 | 接上 | 核对某物料行 | 本期入库数量/金额、直接材料、直接人工、制造费用、单位成本与来源单据一致；单位成本=总成本÷数量 |
| CW-024 | P0 | 同一期间重复执行当期核算 | 连点两次 | 不产生重复物料行或重复明细；数值稳定不翻倍 |
| CW-025 | P1 | 成本核算单已生效/已确认 | 再执行当期核算 | 该物料跳过，不被覆盖（生效快照保护） |
| CW-026 | P1 | 成本核算配置 | 修改配置项 → 重算 | 按新配置重算；历史已生效快照不变 |
| CW-027 | P2 | 某物料无当期业务 | 查看 | 不出现空行或 0 行噪音（按口径记录实际） |

## 五、工序工资核算

| 编号 | 优先级 | 前置条件 | 步骤 | 预期结果 |
|---|---|---|---|---|
| CW-028 | P1 | 有已报工的工序汇报 | 打开工序工资核算 | 按工序/人员汇总计件或计时工资；数量与报工一致 |
| CW-029 | P1 | 调整计件单价配置 | 重新核算 | 金额按新单价重算；已结算的不受影响 |

## 本模块最可能出问题的一条

**CW-013 / CW-014（费用分摊拆分）**：这是刚修过的缺陷——"一个 400 被记到每个物料"变成"按方式拆成 100/300"。验证必须走完整链路：生产入库两行 → 费用分摊审核 → **当期核算** → 在成本核算列表看这两行的直接人工/制造费用列，确认是 100/300；只看到分摊单本身不算数。
