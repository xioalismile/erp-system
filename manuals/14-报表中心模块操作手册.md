## 1. 模块概述

报表中心（路由前缀 `/report`）是系统的自定义数据分析出口，由两类能力组成：

| 子模块 | 路由路径 | 主要能力 | 典型用户 |
|--------|----------|----------|----------|
| 仪表盘 | `/report/dashboard` | 把多张自定义报表组合成一页网格看板（含图表卡片），工作台可自动嵌入默认仪表盘。 | 老板、管理层、业务经理。 |
| 自定义报表 | `/report/custom` | 自助建报表：选数据源（全部业务单据表+明细表+基础资料）→ 配字段/聚合/关联/计算列 → 运行查询、看图表、导出 Excel。 | 财务、业务经理、仓管。 |

另外两个标准财务对账工具挂载在业务模块下（不属于报表中心菜单，但同属本手册范围）：

| 页面 | 路由路径 | 主要能力 | 典型用户 |
|------|----------|----------|----------|
| 客户对账单 | `/sale/report/customer-statement` | 按客户汇总期初/本期应收发生/收款/期末余额，可下钻单据明细，导出 Excel。 | 财务应收会计、销售。 |
| 供应商对账单 | `/purchase/report/supplier-statement` | 按供应商汇总期初/本期应付发生/付款/期末余额，可下钻单据明细，导出 Excel。 | 财务应付会计、采购。 |

核心设计思路：
- **自助分析**：报表字段、口径、关联关系由用户在「报表设计器」里自助配置，不需要开发写代码。
- **数据权限强制**：自定义报表的查询在后端 SQL 层按角色数据权限强制过滤（如销售角色只能查销售域数据源），菜单对所有角色可见但数据各人看各人的。
- **对账单开箱即用**：客户/供应商对账单是固定口径的标准报表，无需配置，进页面即查。

## 2. 进入方式与权限说明

### 2.1 进入方式

- **自定义报表**：左侧导航「报表中心」→「自定义报表」。
- **仪表盘**：左侧导航「报表中心」→「仪表盘」。
- **客户对账单**：左侧导航「销售管理」→「报表」→「客户对账单」。
- **供应商对账单**：左侧导航「采购管理」→「报表」→「供应商对账单」。
- **工作台**：若存在默认（或第一个启用的）仪表盘且其中有图表卡片，工作台首页会自动嵌入展示。

### 2.2 权限说明

- 报表中心菜单对所有角色开放；**数据级权限由后端在 SQL 层强制过滤**——例如销售角色即使配了一张采购数据源的报表，运行时也查不到采购数据。
- 自定义报表支持「共享范围」配置：私有（仅创建人可见）或共享（全公司可见），详见 3.4。
- 对账单页面随销售/采购模块权限走。

> 注意：菜单权限在登录时缓存到 menuRoutePaths，新建/调整菜单后需**重新登录**才能看到变化。

## 3. 自定义报表

### 3.1 功能说明

自定义报表是自助式报表工具，典型用途：
- 把任意业务单据表（销售订单、采购入库、库存台账…）的字段拉成一张查询报表；
- 汇总模式做分组统计（如按客户/月份汇总销售额）；
- 跨单据关联挂指标（如销售订单表上挂「已发数量」「已收金额」「采购入库数量」）；
- 用计算列做加减乘除（如「未发数量 = 订单数量 - 已发数量」）。

### 3.2 报表列表页

进入「报表中心 → 自定义报表」即列表页：

- **筛选**：报表名称/编码关键字 + 查询/重置。
- **新建报表**：右上主按钮，进入空白设计器。
- **列表列**：报表编码、报表名称（蓝色链接=点击直接运行）、数据源、状态（启用/停用）、共享范围（共享/私有）、创建人、创建时间。
- **操作**：运行 / 编辑（进设计器）/ 复制（以现有报表为模板复制一份）/ 删除。
- 底部分页（20/50/100）。

### 3.3 报表设计器

设计器按页签组织：基本信息、字段、关联、筛选、共享。

#### ① 基本信息
- **报表名称**（必填，≤100 字）。
- **数据源**（必填）：分组下拉，覆盖全部业务单据主表、明细表、基础资料（销售/采购/库存/生产/财务/基础资料等分组）。
- **报表模式**：
  - **明细模式**：一行=一条单据/明细记录，适合查流水。
  - **汇总模式**：按分组字段聚合（GROUP BY），适合做统计表。
- **图表类型**：运行页「图形」页签的展示形式（表格/柱状/折线/饼图等）。
- **备注**（可选）。

#### ② 字段
- 左侧字段树支持**搜索字段**，勾选即加入报表输出列。
- 汇总模式下额外配置：
  - **分组字段**：日期字段可选分组粒度（按天/按月/按季/按年）。
  - **聚合指标**：函数 SUM / COUNT / AVG / MAX / MIN；字段可选「行数（COUNT *）」统计单据张数；每个指标可自定义显示名；可勾选**环比%**自动计算环比。
- **计算列**：指标/字段 A 与 B（或常量 B）之间做 ＋ － × ÷ 运算，可命名（如「剩余数量」「未收金额」）。除零或空值时结果为空，页面显示空白。

#### ③ 关联（跨单据挂指标）
在主数据源之外关联其他单据表，把别的单据的量/金额挂到本报表：
- **平铺关联**：目标表字段按单号等字段直接 JOIN 进来（行数可能与主表一致，注意别行翻倍）。
- **聚合挂载**（推荐）：对目标表按关联键做子查询聚合（如 SUM 已发数量）后 1:1 挂回主表，不会行翻倍。聚合指标可配：
  - **来源表**：目标主表 或 目标明细表（如「已发数量」取销售出库明细 SUM(quantity)）。
  - **函数**：SUM/COUNT/AVG/MAX/MIN；来源为主表时可选「单据数 COUNT(*)」统计关联单张数。
- **两跳追溯（via）**：目标单与主表无直接单号关联时，配「经中间表」跳板。语义：`主表.单号 = 跳板.来源单号`，`跳板.单号 = 目标.来源单号`（例：销售订单 →（采购订单）→ 采购入库数量）。需分别指定跳板单号字段和跳板来源单号字段；跳板最多 1 层（两跳）。

#### ④ 筛选
为运行页预置筛选入口：
- **日期筛选字段**：指定哪个日期字段接受日期范围筛选。
- **关键字筛选字段**：指定哪个文本字段接受关键字（如单号/名称）。
- **状态筛选字段**：指定哪个字段接受状态下拉。
- **默认排序**：字段 + 升序/降序（汇总模式下排序字段应为分组字段或聚合指标，非分组列会被忽略以保证 SQL 正确）。

#### ⑤ 共享
- **共享范围**：私有（仅自己可见）/ 共享（全公司可见）。

### 3.4 报表运行页

从列表点报表名称或「运行」进入：
- 顶部：报表名称 + **导出Excel** 按钮。
- 筛选条：日期范围 / 关键字 / 状态（按设计器筛选页签的配置显示）。
- **图形页签**：按设计器配置的图表类型渲染（饼图时展示各指标占比）。
- **数据页签**：表格展示查询结果，底部合计行汇总数值列，分页浏览。

### 3.5 操作步骤（从零建一张报表）

以「销售订单发货情况表」为例：
1. 列表页点「新建报表」。
2. 基本信息：名称填「销售订单发货情况表」，数据源选「销售订单」，模式选「明细」。
3. 字段页签：勾选单据编号、单据日期、客户名称、业务员、数量、金额。
4. 关联页签：新增关联 → 目标选「销售出库」，聚合挂载 → 聚合指标 = 明细表 quantity SUM，显示名「已发数量」。
5. 计算列：字段A=数量，字段B=已发数量，运算=－，列名「未发数量」。
6. 筛选页签：日期筛选字段选单据日期，关键字字段选单据编号，默认排序=单据日期降序。
7. 保存 → 运行 → 校验数值 → 导出 Excel 或加入仪表盘。

## 4. 自定义仪表盘

### 4.1 功能说明

仪表盘把多张**汇总模式**自定义报表组合成一页网格看板（2×2 布局），每张报表一个卡片（表格或图表）。典型用途：老板一页看「本月销售额 / 采购额 / 应收余额 / 库存余额」。

### 4.2 页面说明

- **仪表盘列表**（`/report/dashboard`）：查看已有仪表盘，新建 / 编辑 / 查看。
- **仪表盘设计器**（`/report/dashboard/designer`）：选择引用哪些自定义报表、排列卡片、设置默认仪表盘。
- **仪表盘查看**（`/report/dashboard/view/:id`）：网格渲染各卡片。
- **工作台嵌入**：工作台首页自动寻找「默认仪表盘」（无默认则取第一个启用的），只展示含汇总/图表的卡片（最多 4 张）；无可用仪表盘或加载失败时整块隐藏，不影响工作台其他内容。

### 4.3 注意事项

- 卡片级错误隔离：某一张被引用的报表配置错了或没权限，只有该卡片显示「不可用」，不影响其他卡片。
- 仪表盘可见性 = 仪表盘共享设置 ∩ 每张被引用报表的可见性（引用了私有报表的卡片别人看不到）。

## 5. 客户对账单

### 5.1 功能说明

按客户汇总「应收往来」的标准对账报表，开箱即用：
- **汇总统计**：一客户一行，展示期初应收余额、本期发生（销售订单/销售出库/销售发票/销售退货金额）、本期应收合计、本期收款金额、期末应收余额、单据数、最后交易日期。
- **明细统计**：一行一条单据（销售订单/销售出库/销售发票/销售退货/收款单/期初），展示应收金额、已收金额、余额、源单号。
- **导出 Excel**：按当前筛选条件导出。

### 5.2 界面与操作

**筛选区**（页面顶部）：
- 日期范围（开始~结束日期）。
- 单据编号（关键字）。
- 客户编号 / 客户名称。
- 按钮：查询 / 重置 / 导出Excel。

**汇总统计页签**（默认）：
- 表格列：客户编号、客户名称（左侧固定列）、期初应收余额、本期发生（四列分组：销售订单金额/销售出库金额/销售发票金额/销售退货金额）、本期应收合计、本期收款金额、期末应收余额（正数红色加粗=客户欠款）、单据数、最后交易日期。
- 表尾自动合计所有金额列与单据数。
- **点击任意行 → 自动把该客户填入筛选条件并切换到「明细统计」页签**（页面有提示「已切换至明细统计：xxx」），实现汇总→明细下钻。

**明细统计页签**：
- 表格列：单据日期、单据类型（彩色标签）、单据编号、客户编号、客户名称、应收金额、已收金额、余额、源单号、备注。
- 表尾合计应收/已收/余额；底部支持翻页与每页条数（20/50/100/200）。

**导出**：点「导出Excel」下载 `客户对账单.xlsx`（按当前筛选条件导出）。

### 5.3 操作步骤（月度对账标准流程）

1. 进入「销售管理 → 报表 → 客户对账单」。
2. 日期范围选上月初~上月末（不选=全部期间）。
3. 可按客户编号/名称过滤特定客户，或直接查询全部。
4. 汇总页核对每个客户的期末应收余额。
5. 对有疑问的客户：点击该客户行 → 自动下钻到明细页签 → 逐单核对来源单据。
6. 点「导出Excel」留存或发给客户对账。

### 5.4 注意事项

- 页签切换/查询条件变化都会重新请求对应页签数据；汇总页签不分页（一次返回全部），明细页签分页。
- 数据加载失败时页面显示空表并提示「数据加载失败，请检查网络连接或联系管理员」，不会展示虚假数据。
- 对账口径=已生效业务单据；如发现金额与预期不符，先到销售/财务模块确认单据状态。

## 6. 供应商对账单

### 6.1 功能说明

与客户对账单完全对称，方向为「应付」：
- **汇总统计**：一供应商一行——期初应付余额、本期发生（采购订单/采购入库/采购发票/采购退货金额）、本期应付合计、本期付款金额、期末应付余额（正数=我方欠供应商）、单据数、最后交易日期。
- **明细统计**：一行一条单据（采购订单/采购入库/采购发票/采购退货/付款单/期初），含应付金额、已付金额、余额、源单号。
- 支持汇总→明细点击下钻、导出 Excel。

### 6.2 界面与操作

页面结构、筛选条件（日期范围/单据编号/供应商编号/供应商名称）、页签交互、合计行、分页、导出行为与第 5 章客户对账单一致，字段名按「客户→供应商、应收→应付、收款→付款」对应替换。

进入路径：「采购管理 → 报表 → 供应商对账单」（`/purchase/report/supplier-statement`）。

## 7. 附录A：标准台账下线说明

原标准台账子系统（5 个后端 StandardReportController + 3 个前端页面 + standardReports 目录 + 21 条路由 + 20 个菜单）已于 2026-08-31 删除，原因：功能与自定义报表重叠、维护成本高。处理方式：

| 原需求 | 现替代方案 |
|--------|------------|
| 各模块明细表（销售订单明细表、库存台账等 20 个菜单） | 用「自定义报表」明细模式自建：数据源选对应单据表 → 勾字段 → 配筛选 → 保存共享。 |
| 跨单统计（收发存、账龄等） | 用「自定义报表」汇总模式 + 聚合挂载/两跳追溯配置。 |
| 客户/供应商对账单 | **保留未删**，移至 销售/采购 → 报表 菜单（本手册第 5/6 章）。 |

数据库清理：`48_drop_standard_report_menus.sql`（幂等）删除 20 个菜单及权限残留，已进部署套件 manifest，历史服务器通过正常部署自动完成清理。`46_custom_report_menus.sql` 同步去掉标准台账菜单的再插入逻辑。

## 8. 附录B：常见问题

### Q1：新建的自定义报表，别人能看到吗？
A：默认私有。在设计器「共享」页签把共享范围改为「共享」后全公司可见。仪表盘引用了私有报表的卡片，其他人看不到该卡片。

### Q2：自定义报表运行报错或查不到数据？
A：按顺序排查：
1. **数据权限**：后端按角色数据权限过滤（销售角色查采购数据源=查不到），换管理员账号验证。
2. **汇总模式排序**：排序字段必须选分组字段或聚合指标，配了非分组列会被自动忽略（这是正常保护，不是 bug）。
3. **关联配置**：跨单关联前先确认来源单号字段在实际数据里真的存了值（如收款单的关联键是 orderNo 不是 sourceBillNo，因表而异）。
4. **混配限制**：同一个聚合挂载里，主表字段与明细表字段不能混配（明细 JOIN 会扇出放大主表 SUM）——要数量+金额请拆成两个关联。

### Q3：汇总数字和单据列表对不上？
A：常见原因：
1. 报表未按状态过滤，把草稿/未生效单据算进去了（或反之）。
2. 聚合挂载的关联键匹配到了多张单（如一张订单多次入库），确认业务口径是否应该累计。
3. 日期筛选字段选错（制单日期 vs 审核日期）。

### Q4：对账单某客户期末余额感觉不对？
A：用汇总→明细下钻（点击该客户行）逐单核对：期初余额 + 本期应收 - 本期收款 = 期末。若明细里有不该计入的单据（未生效/已作废），先回业务模块处理单据状态，再回来重新查询。

### Q5：工作台上看不到仪表盘卡片？
A：依次确认：
1. 是否存在启用的仪表盘（无任何仪表盘时工作台整块隐藏，属正常）。
2. 仪表盘里是否有**汇总模式**报表卡片（工作台只展示汇总+图表卡片，明细报表卡片不嵌入）。
3. 图表加载失败时该卡片也会隐藏，进仪表盘页面本身核对配置。

### Q6：导出的 Excel 打开是空白或数据不全？
A：先在页面上确认当前筛选条件下确实有数据；导出按当前筛选条件执行，筛选太严会导致导出空表。数据量大时等浏览器下载完成再打开。

### Q7：以前菜单里的「销售订单明细表」「库存台账」去哪了？
A：已随标准台账整体下线（见附录A），用自定义报表自建同名报表即可，字段可以配得比原来更全。
